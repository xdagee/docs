## 1. The Call to Adventure

Imagine walking into a dark room and simply clapping to turn on the lights.
Your mission is to calibrate a high-sensitivity microphone (Sound Sensor) to detect noise levels and report them to the control center.

## 2. The Toolkit

* **3x Jumper Wires**

## 3. The Blueprint

* **VCC** -> **5V**
* **GND** -> **GND**
* **OUT** -> **Pin A0** (Analog)

![Sound Sensor Wiring](../../assets/1.0/Sound_Sensor/green.webp)

## 4. The Logic

The sensor converts sound vibrations into a voltage number (0-1023).

* **Silence**: Low number (e.g., 20-50).
* **Clap**: High spike (e.g., 400+).

### The Code

```cpp
// Mission 1.36: The Clapper
const int soundPin = A0;

void setup() {
  Serial.begin(9600); // Start communication
}

void loop() {
  int noise = analogRead(soundPin);
  
  // Send data to the computer
  Serial.println(noise);
  
  delay(10); // Capture fast sound spikes
}
```

## 5. Upload & Test

1. Upload the code.
2. **Open Serial Plotter**: Tools > Serial Plotter (or CTRL+SHIFT+L).
3. Stay silent. Then **CLAP**. Do you see the spike on the graph?

## 6. Troubleshooting

* **Always a flat line?**
  * **Calibration**: Locate the tiny screw (Potentiometer) on the sensor. Turn it until the Red LED on the module just turns off. This sets the "Sensitivity".
* **Static noise?** Keep the sensor away from large motors or computer fans, as they create invisible electric noise.
