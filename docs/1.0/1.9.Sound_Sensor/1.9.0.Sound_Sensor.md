## 1. The Call to Adventure

Imagine walking into a room and turning on the lights just by clapping. That's not magic; it's engineering.
Your mission is to calibrate a sensor to detect the specific sound pattern of a "Clap".

## 2. The Toolkit

## 3. The Blueprint

* **VCC** -> **5V**
* **GND** -> **GND**
* **OUT (Signal)** -> **Pin A0** (Analog)

![Sound Sensor Wiring](../../assets/1.0/Sound_Sensor/green.webp)

## 4. The Logic

The sensor converts sound waves into electricity.

* **Quiet** = Low Number.
* **Loud** = High Number.

**Step-by-Step:**

1. **Define**: Pin A0.
2. **Read**: `analogRead(A0)`.
3. **Inspect**: Watch the Serial Plotter to see the sound waves.

### The Code

```cpp
// Mission 1.9: Clap Sensor
const int soundPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int noiseLevel = analogRead(soundPin);
  
  // Print to Serial Plotter (Tools > Serial Plotter)
  Serial.println(noiseLevel);
  
  delay(10); // Very fast updates to catch the clap
}
```

## 5. Upload & Test

1. Upload code.
2. **Open Serial Plotter** (CTRL+SHIFT+L) or Tools > Serial Plotter.
3. Clap your hands! Do you see a spike in the blue line?

## 6. Troubleshooting

* **Flat line? (Not reacting)**
  * **Sensitivity**: Locate the blue box on the sensor. Use a small screwdriver to turn the screw on top until the red LED on the module *just* turns off (or flickers).
* **Always Max Value?**
  * Check GND and VCC connections.

## 7. Extensions & Upgrades

**Challenge**: The Clap Switch

* **Upgrade**: Turn on an LED when the sound is loud.
