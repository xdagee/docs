## 1. The Call to Adventure

Late at night, when there are few cars, many intersections switch to "Caution Mode".
Your mission is to pulse the Yellow light to tell drivers: "I'm on standby. Be careful!"

## 2. The Toolkit

* **1x Traffic Light Module**
* **1x Arduino Uno**
* **4x Jumper Wires**

## 3. The Blueprint

* **Y (Yellow)** -> **Pin 6**
* **GND** -> **GND**

## 4. The Logic

**Algorithm:**

1. Turn Pin 6 ON.
2. Wait 400ms.
3. Turn Pin 6 OFF.
4. Wait 400ms.

### The Code

```cpp
// Mission 1.21: The Caution Flash
const int yellow = 6;

void setup() {
  pinMode(yellow, OUTPUT);
}

void loop() {
  digitalWrite(yellow, HIGH); 
  delay(400);
  digitalWrite(yellow, LOW);
  delay(400);
}
```

## 5. Upload & Test

1. Upload the code.
2. Observe the signal. Does it feel like a "Standby" mode?
3. **Challenge**: Can you make the blink "irregular"? Long ON, Very short OFF.

## 6. Troubleshooting

* **Blinking too fast?** Increase the `delay()` number.
* **Pin mismatch?** Red is 5, Yellow is 6, Green is 7. Ensure your code matches the wire!
