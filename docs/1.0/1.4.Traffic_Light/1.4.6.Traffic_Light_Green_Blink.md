## 1. The Call to Adventure

Sometimes drivers are distracted while waiting in traffic. A pulsing Green light can grab their attention more effectively than a steady one.
Your mission is to program the "GO" signal to pulse, ensuring everyone notices when the road opens.

## 2. The Toolkit

* **1x Traffic Light Module**
* **1x Arduino Uno**
* **4x Jumper Wires**

## 3. The Blueprint

## 4. The Logic

**Algorithm:**

1. Turn Pin 7 ON.
2. Wait 400ms.
3. Turn Pin 7 OFF.
4. Wait 400ms.

### The Code

```cpp
// Mission 1.23: The Awareness Pulse
const int green = 7;

void setup() {
  pinMode(green, OUTPUT);
}

void loop() {
  digitalWrite(green, HIGH); 
  delay(400);
  digitalWrite(green, LOW);
  delay(400);
}
```

## 5. Upload & Test

1. Upload the code.
2. Watch the signal. Does it feel like an invitation to move?
3. **Master Challenge**: Can you combine everything? Red ON (2s) -> Yellow ON (1s) -> Green ON (2s) -> Loop.

## 6. Troubleshooting

* **No blinking?** Check the spelling of `digitalWrite` and `delay`. Code is case-sensitive!
* **Green light not working?** Ensure your wire labeled 'G' on the module is connected to **Pin 7** on the Arduino.
