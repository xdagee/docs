## 1. The Call to Adventure

Changing instantly from Stop to Go is dangerous. Drivers need a "Ready" signal.
Your mission is to enable the middle beacon of your system to provide a transition phase.

## 2. The Toolkit

* **1x Traffic Light Module**
* **1x Arduino Uno**
* **4x Jumper Wires**

## 3. The Blueprint

* **Y (Yellow)** -> **Pin 6**
* **GND** -> **GND**

![Wiring Diagram](../../assets/1.0/Traffic_Light_Module/Traffic_Light_Red_On/yellow_trafic_1.webp)

## 4. The Logic

**Algorithm:**

1. **Define**: `yellowLight` is Pin 6.
2. **Setup**: Pin 6 as `OUTPUT`.
3. **Loop**: Turn Pin 6 `HIGH`.

### The Code

```cpp
// Mission 1.20: Yellow Means Ready
const int yellowLight = 6;

void setup() {
  pinMode(yellowLight, OUTPUT);
}

void loop() {
  digitalWrite(yellowLight, HIGH); // GET READY!
}
```

## 5. Upload & Test

1. Upload the code.
2. Does the center light glow?
3. **Upgrade**: Can you write code that turns the Red light OFF and the Yellow light ON at same time?

## 6. Troubleshooting

* **Light is Red?** You might still be using Pin 5 in your code. Change it to `6`.
* **Module loose?** Ensure the Traffic Light module is pushed all the way into the breadboard or breadboard wires.
