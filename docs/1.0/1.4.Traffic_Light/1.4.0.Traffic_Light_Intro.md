# Mission 1.17: The Unsafe Intersection

> **Role**: Lead Safety Engineer  
> **Objective**: Building the infrastructure for a smart city.

## 1. The Call to Adventure

**Location:** The busiest road in your community.  
**The Problem:** Cars, bicycles, and pedestrians are all trying to cross at the same time. It's dangerous! The community needs a system to tell people when to **STOP** and when to **GO**.

Your mission is to build and program an automated **Traffic Light System**.

---

## 2. The Toolkit

To solve this, you will need:

* **1x Traffic Light Module**: A pre-built set of 3 digital beacons (Red, Yellow, Green).
* **1x Arduino Uno**: The brain that controls the timing.
* **4x Jumper Wires**: To connect the brain to the signals.

## 3. The Blueprint (Wiring)

We use a standard wiring plan to ensure every module behaves the same.

| Traffic Light Pin | Arduino Pin |
| :---: | :---: |
| **GND (-)** | **GND** |
| **R (Red)** | **Pin 5** |
| **Y (Yellow)** | **Pin 6** |
| **G (Green)** | **Pin 7** |

## 4. The Logic (Code Strategy)

Before writing code, good engineers plan. We will use `const int` to give our pins names. This makes the code readable for humans!

```cpp
// Naming our beacons
const int red = 5;
const int yellow = 6;
const int green = 7;
```
