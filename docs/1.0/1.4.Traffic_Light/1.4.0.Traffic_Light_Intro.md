# Mission 1.4: The Unsafe Intersection (Traffic Light)

## 1. The Call to Adventure

**Location:** The busiest road in your community.
**The Problem:** Cars, bicycles, and pedestrians are all trying to cross at the same time. It's dangerous! The community needs a system to tell people when to **STOP** and when to **GO**.

**Your Objective:**
As the **Lead Engineer**, you must build an automated **Traffic Light System**.

* **Red Light**: Stop everyone. Dangerous! (Pin 5)
* **Yellow Light**: Warning. Get ready. (Pin 6)
* **Green Light**: Safe to go. (Pin 7)

## 2. The Toolkit

To solve this, you will need:

* **Traffic Light Module**: A pre-built set of 3 digital beacons.
* **Arduino Uno**: The brain that controls the timing.

## 3. The Blueprint (Wiring)

We need to connect our beacons to the brain. We use the **Standard Wiring**:

| Traffic Light Pin | Arduino Pin |
| :---: | :---: |
| **GND (-)** | **GND** |
| **R (Red)** | **Pin 5** |
| **Y (Yellow)** | **Pin 6** |
| **G (Green)** | **Pin 7** |

## 4. The Logic (Code Strategy)

Before writing code, good engineers plan. We will use `const int` into give our pins names.

```cpp
// Naming our tools
const int red = 5;
const int yellow = 6;
const int green = 7;
```

Now, we can just say `digitalWrite(red, HIGH);` instead of remembering numbers.
