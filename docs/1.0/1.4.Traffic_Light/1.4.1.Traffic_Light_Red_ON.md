## 4. The Logic

**Algorithm:**

1. **Define**: `redLight` is Pin 5.
2. **Setup**: Configure Pin 5 as **OUTPUT**.
3. **Loop**: Turn Pin 5 **HIGH** (ON).

### The Code

```cpp
// Mission 1.18: The Red Signal
const int redLight = 5;

void setup() {
  pinMode(redLight, OUTPUT);
}

void loop() {
  digitalWrite(redLight, HIGH); // STOP!
}
```

## 5. Upload & Test

1. Upload the code.
2. Is the Red LED glowing?
3. **Challenge**: Can you turn the light OFF by changing one word in the code?

## 6. Troubleshooting

* **No light?**
  * **Ground Check**: Is the GND pin connected? The module needs it to complete the circuit.
* **Wrong color?** Trace the wires. Did you accidentally plug Pin 5 into 'Y' or 'G'?
