# Project 1.4.1: Red Means STOP

## 1. The Concept: Naming Things

**What are we learning?**
We are going to turn on the **Red Light** of the traffic module.
But this time, we will use a **Variable** to give the pin a name.

Instead of remembering "Pin 5", we will tell the computer:
> *"Hey computer, whenever I say 'RedLight', I mean Pin 5!"*

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Give the pin a name!
const int redLight = 5;

void setup() {
  // 2. Configure the pin as OUTPUT
  pinMode(redLight, OUTPUT);
}

void loop() {
  // 3. Turn it ON
  digitalWrite(redLight, HIGH);
}
```

### Explaining the Code

* `const int redLight = 5;`: We create a constant integer named `redLight` and store the number `5` in it.
* `digitalWrite(redLight, HIGH);`: The computer reads this as "Write HIGH to Pin 5".

## 6. Troubleshooting

* **No light?** Check the GND connection. The module needs GND to complete the circuit.
* **Wrong light on?** You might have connected Pin 5 to the Yellow or Green pin by mistake. Check the letters on the module (R, Y, G).
* **All lights on?** You might be powering them directly from 5V instead of a Pin. Check your wiring.
