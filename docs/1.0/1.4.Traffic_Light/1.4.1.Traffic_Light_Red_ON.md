## 1. The Call to Adventure

Safe roads need rules. We communicate these rules using light signals.
Your mission is to take control of the intersection. We start with the most important signal: **STOP**.

## 2. The Toolkit

* **1x Traffic Light Module**
* **1x Arduino Uno**
* **1x Breadboard** (Optional, can plug directly)

## 3. The Blueprint

The Traffic Light module has 4 pins.

* **GND** -> **GND** (The Common Ground)
* **R (Red)** -> **Pin 5**
* **Y (Yellow)** -> **Pin 6**
* **G (Green)** -> **Pin 7**

![Traffic Light Wiring](../../assets/1.0/Traffic_Light_Module/Traffic_Light_Red_On/Traffic_Light_image_2.webp)

## 4. The Logic

We use variables to keep our code clean. Instead of remembering "5", we call it `redLight`.

**Step-by-Step:**

1. **Define**: `redLight` is Pin 5.
2. **Setup**: Configure Pin 5 as **OUTPUT**.
3. **Loop**: Turn Pin 5 **HIGH** (ON).

### The Code

```cpp
// Mission 1.4: Traffic Control
const int redLight = 5;

void setup() {
  pinMode(redLight, OUTPUT);
}

void loop() {
  digitalWrite(redLight, HIGH); // STOP!
}
```

## 5. Upload & Test

## 6. Troubleshooting

* **No light?**
  * **Ground Check**: Is the GND pin connected? The module needs it to complete the circuit.
* **Wrong color?**
  * Trace the wires. Did you accidentally plug Pin 5 into 'Y' or 'G'?
* **Very dim?**
  * Ensure your wires are fully inserted.
