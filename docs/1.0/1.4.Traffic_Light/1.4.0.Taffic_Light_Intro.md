# Introduction to the Traffic Light Module

## 1. What is it?

The **Traffic Light Module** looks fancy, but it is actually very simple: **It is just 3 LEDs (Red, Yellow, Green) stuck together.**

Instead of using 3 separate LEDs and 3 resistors on a breadboard, this module keeps everything tidy.

### How it works

* It has **4 Pins**:
    1. **GND (-):** The negative leg shared by all three lights.
    2. **R (+):** Turns on the Red light.
    3. **Y (+):** Turns on the Yellow light.
    4. **G (+):** Turns on the Green light.

## 2. Standard Wiring

For all our Traffic Light projects, we will use this standard wiring. This makes it easy to switch between projects!

| Traffic Light Pin | Arduino Pin |
| :---: | :---: |
| **GND (-)** | **GND** |
| **R (Red)** | **Pin 5** |
| **Y (Yellow)** | **Pin 6** |
| **G (Green)** | **Pin 7** |

## 3. Why use "const int"?

In our code, we don't want to keep remembering "Pin 5 is Red". That's confusing.
Instead, we give the pins names at the start of our code:

```cpp
const int red = 5;
const int yellow = 6;
const int green = 7;
```

Now, we can just write `digitalWrite(red, HIGH);` and the computer knows we mean Pin 5!

* **const**: Means "Constant" (This number will never change while the program runs).
* **int**: Means "Integer" (A whole number).
