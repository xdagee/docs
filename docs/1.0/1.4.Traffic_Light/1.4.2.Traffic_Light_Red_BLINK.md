## 1. The Call to Adventure

Sometimes, a steady light isn't enough to grab attention. When there is danger, we use a flashing beacon.
Your mission is to program the Red light to blink, signaling that the road is closed or an emergency is happening.

## 2. The Toolkit

* **1x Traffic Light Module**
* **1x Arduino Uno**
* **4x Jumper Wires**

## 3. The Blueprint

* **R (Red)** -> **Pin 5**
* **GND** -> **GND**

![Wiring Diagram](../../assets/1.0/Traffic_Light_Module/Traffic_Light_Red_On/Traffic_Light_image_2.webp)

## 4. The Logic

**Algorithm:**

1. Turn Pin 5 ON.
2. Wait 400ms.
3. Turn Pin 5 OFF.
4. Wait 400ms.

### The Code

```cpp
// Mission 1.19: The Danger Flash
const int red = 5;

void setup() {
  pinMode(red, OUTPUT);
}

void loop() {
  digitalWrite(red, HIGH); // Beep! (Just kidding, it's a light)
  delay(400);
  digitalWrite(red, LOW);
  delay(400);
}
```

## 5. Upload & Test

1. Upload the code.
2. Observe the Red light. Does it feel urgent?
3. **Experiment**: Change `delay(400)` to `delay(100)` for a faster "Panic" flash.

## 6. Troubleshooting

* **Light stays ON?** Check if you have both `HIGH` and `LOW` commands in your loop.
* **Light flashes once and stops?** Ensure the code is inside the `void loop() { ... }` curly brackets.
