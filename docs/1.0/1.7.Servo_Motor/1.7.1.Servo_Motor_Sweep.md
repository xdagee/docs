## 1. The Call to Adventure

A stationary sensor has blind spots. To see everything, we need to move.
Your mission is to program the Servo to "Sweep"—moving one degree at a time to create a fluid, scanning motion like a radar dish.

## 2. The Toolkit

* **1x Micro Servo**
* **1x Arduino Uno**
* **3x Jumper Wires**

## 3. The Blueprint

* **Brown/Black** -> **GND**
* **Red** -> **5V**
* **Orange/Yellow** -> **Pin 10**

## 4. The Logic

We use **`for` loops** to move the servo one small step at a time. This makes the movement look professional and smooth.

### The Code

```cpp
// Mission 1.34: The Radar Sweep
#include <Servo.h>

Servo scanner;
int pos = 0; // Current position

void setup() {
  scanner.attach(10);
}

void loop() {
  // 1. Sweep from 0 to 180
  for (pos = 0; pos <= 180; pos += 1) {
    scanner.write(pos);
    delay(15); // Wait for the arm to reach the position
  }
  
  // 2. Sweep back from 180 to 0
  for (pos = 180; pos >= 0; pos -= 1) {
    scanner.write(pos);
    delay(15);
  }
}
```

## 6. Troubleshooting

* **Movement is jerky?** Ensure your `delay()` is at least `10ms`. The motor needs time to physically move to each degree!
* **Stuck at one side?** Check your `for` loop logic. Did you use `<` or `>` correctly?
