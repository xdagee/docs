# Project 1.7: The Robot Arm (Servo Motor)

## 1. The Concept: Precision Movement

**What are we learning?**
Normal motors spin around and around (like a fan).
**Servo Motors** are different. They go to a specific **angle** (like 90°) and STOP.
They are used in robot arms, car wipers, and airplane rudders.

To control them, we need a special "Toolbox" of code called a **Library**.
`#include <Servo.h>`

## 3. Wiring the Circuit

The Servo has 3 wires attached to it. They are color-coded:

| Wire Color | Connection | Arduino Pin |
| :---: | :---: | :---: |
| **Brown** (or Black) | Ground | **GND** |
| **Red** | Power | **5V** |
| **Orange** (or Yellow) | Signal | **Pin 10** |

![Servo Wiring](../../assets/1.0/Servo_Motor/One_Angle/orange_10.webp)

> **Caution:** Do not force the servo arm with your hands. You might break the gears!

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Grab the "Toolbox" for servos
#include <Servo.h> 

// 2. Give our servo a name
Servo myArm; 

void setup() {
  // 3. Tell Arduino where the servo is connected (Pin 10)
  myArm.attach(10);
}

void loop() {
  // 4. Move to 0 degrees
  myArm.write(0);
  delay(1000); // Wait 1 second

  // 5. Move to 90 degrees
  myArm.write(90);
  delay(1000);

  // 6. Move to 180 degrees (Max)
  myArm.write(180);
  delay(1000);
}
```

### Explaining the Library

* `#include <Servo.h>`: This tells the computer "I am using a Servo, please load the special commands".
* `myArm.attach(10)`: This connects the software "myArm" to the hardware "Pin 10".
* `myArm.write(90)`: This acts like the steering wheel. It tells the servo exactly where to point.

## 5. Upload & Test

1. **Verify** and **Upload**.
2. Watch the arm. It should move Left -> Middle -> Right -> Repeat.

## 6. Troubleshooting

* **Arm just vibrates?** You might have low power. Try using a different USB port.
* **Nothing happens?** Check the **Red** and **Brown** wires. They are often mixed up.
  * Red -> 5V
  * Brown -> GND
* **Moves nicely but stops working?** Ensure wires are tight. Servos vibrate a lot and can shake wires loose!
