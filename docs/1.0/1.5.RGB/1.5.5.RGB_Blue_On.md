## 1. The Call to Adventure

Blue is the color of the sky and the ocean. It is often used to signal calmness or "Cold" temperatures.
Your mission is to activate the final primary channel of your RGB module: Blue.

## 2. The Toolkit

* **1x RGB LED Module**
* **2x Jumper Wires**
* **1x Arduino Uno**

## 3. The Blueprint

* **B (Blue)** -> **Pin 5**
* **- (Common)** -> **GND**

![Blue Wiring](../../assets/1.0/RGB/BLUE_G_B/circuit_2.webp)

## 4. The Logic

**Algorithm:**

1. Select the Blue pin.
2. Switch to `HIGH`.

### The Code

```cpp
// Mission 1.29: The Sapphire Sky
const int blue = 5;

void setup() {
  pinMode(blue, OUTPUT);
}

void loop() {
  digitalWrite(blue, HIGH);
}
```

## 5. Upload & Test

1. Upload the code.
2. Check the "Sapphire"—is it deep and clear?
3. **Upgrade**: Turn on Blue and Red together. What magic happens? (Purple/Magenta!)

## 6. Troubleshooting

* **Yellowest-Blue?** If it looks yellow, you probably have Green or Red pinned instead. Blue is the 3rd data pin.
* **Wires tangled?** Clear your breadboard for the final mixing missions!
