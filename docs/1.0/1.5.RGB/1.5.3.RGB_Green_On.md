## 1. The Call to Adventure

Red means stop, but Green means the system is healthy and active.
Your mission is to calibrate the Green channel to signal that all systems are "GO".

## 2. The Toolkit

* **1x RGB LED Module**
* **2x Jumper Wires**
* **1x Arduino Uno**

## 3. The Blueprint

* **G (Green)** -> **Pin 5**
* **- (Common)** -> **GND**

![Green Wiring](../../assets/1.0/RGB/GREEN_G_B/circuit_2.webp)

## 4. The Logic

**Algorithm:**

1. Target the Green pin.
2. Send power `HIGH`.

### The Code

```cpp
// Mission 1.27: The Emerald Gate
const int green = 5;

void setup() {
  pinMode(green, OUTPUT);
}

void loop() {
  digitalWrite(green, HIGH);
}
```

## 5. Upload & Test

1. Upload the code.
2. Does the Green light shine bright?
3. **Challenge**: Try to make a "Mint" color by turning on both Red and Green (Yellowish-Green).

## 6. Troubleshooting

* **Light is Red?** Verify you are connected to the "G" pin on the module, not the "R".
* **Module upside down?** Labels are usually on one side. Check closely with a flashlight!
