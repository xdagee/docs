## 1. The Call to Adventure

A blinking green light is used in servers and machines to say: "I am working correctly."
Your mission is to create this "System OK" heartbeat using the Green channel.

## 2. The Toolkit

* **1x RGB LED Module**
* **1x Arduino Uno**
* **2x Jumper Wires**

## 3. The Blueprint

* **G (Green)** -> **Pin 5**
* **- (Common)** -> **GND**

![Green Pulse](../../assets/1.0/RGB/GREEN_G_B/circuit_3.webp)

## 4. The Logic

**Algorithm:**

1. Green `HIGH`.
2. Wait.
3. Green `LOW`.

### The Code

```cpp
// Mission 1.28: The Jade Alert
const int green = 5;

void setup() {
  pinMode(green, OUTPUT);
}

void loop() {
  digitalWrite(green, HIGH); delay(500);
  digitalWrite(green, LOW);  delay(500);
}
```

## 5. Upload & Test

1. Upload the code.
2. Does the heartbeat feel steady?
3. **Upgrade**: Can you make it blink in a double-pulse pattern? (Wait very briefly between two flashes).

## 6. Troubleshooting

* **Glow is faint?** Ensure your GND wire is shared with the Arduino GND.
* **Timing off?** Remember: `1000` is one second. `500` is half a second.
