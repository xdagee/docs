## 1. The Call to Adventure

You’ve mastered Red, Green, and Blue individually. Now, it’s time to mix them.
Your mission is to use a special function to cycle through every shade, from the warm Orange of a sunset to the deep Violet of the night sky.

## 2. The Toolkit

* **1x RGB LED Module**
* **4x Jumper Wires** (R, G, B, GND)
* **1x Arduino Uno**

## 3. The Blueprint

**Important:** Connect to **PWM Pins (8, 9, 10)** or (3, 5, 6) depending on your board's mark.

* **R** -> **Pin 8**
* **G** -> **Pin 9**
* **B** -> **Pin 10**
* **-** -> **GND**

![Rainbow Wiring](../../assets/1.0/RGB/RGB_Intro/gnd_wire_connect.webp)

## 4. The Logic

**Algorithm:**

1. Create a "mixing function" called `setColor`.
2. Call this function with different "Recipes" (Red, Green, Blue values).

### The Code

```cpp
// Mission 1.31: The Technicolor Dream
const int red = 8;
const int green = 9;
const int blue = 10;

void setup() {
  pinMode(red, OUTPUT);
  pinMode(green, OUTPUT);
  pinMode(blue, OUTPUT);
}

void loop() {
  // Rainbow Recipes
  setColor(255, 0, 0);   delay(500); // Red
  setColor(255, 127, 0); delay(500); // Orange
  setColor(255, 255, 0); delay(500); // Yellow
  setColor(0, 255, 0);   delay(500); // Green
  setColor(0, 0, 255);   delay(500); // Blue
  setColor(75, 0, 130);  delay(500); // Indigo
  setColor(148, 0, 211); delay(500); // Violet
}

void setColor(int r, int g, int b) {
  analogWrite(red, r);
  analogWrite(green, g);
  analogWrite(blue, b);
}
```

## 5. Upload & Test

1. Upload the code.
2. Wait for the cycle. Do you see all 7 colors?
3. **Upgrade**: Can you create your own "Hidden Color" recipe? (Example: 255, 20, 147 for Deep Pink).

## 6. Troubleshooting

* **Colors skipping?** Check your `delay()`. If it’s too small, the colors will blur together.
* **Only Red/Green works?** Check the Blue wire on Pin 10. Digital pins 8, 9, 10 are all PWM on some boards, but on others ONLY 9 and 10 are. Check for the `~` symbol!
