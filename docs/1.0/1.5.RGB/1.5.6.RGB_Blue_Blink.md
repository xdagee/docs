## 1. The Call to Adventure

Navigators use pulsing blue lights to mark docking stations or cold zones.
Your mission is to program the Blue channel to pulse, guiding nearby travelers to your station.

## 2. The Toolkit

* **1x RGB LED Module**
* **2x Jumper Wires**
* **1x Arduino Uno**

## 3. The Blueprint

* **B (Blue)** -> **Pin 5**

## 4. The Logic

**Algorithm:**

1. Blue `ON`.
2. Wait.
3. Blue `OFF`.

### The Code

```cpp
// Mission 1.30: The Azure Beacon
const int blue = 5;

void setup() {
  pinMode(blue, OUTPUT);
}

void loop() {
  digitalWrite(blue, HIGH); delay(800);
  digitalWrite(blue, LOW);  delay(800);
}
```

## 5. Upload & Test

1. Upload the code.
2. Watch the beacon cycle. Is it bright enough?
3. **Upgrade**: Can you create a "fading" Beacon using `analogWrite`?

## 6. Troubleshooting

* **Blinks too slowly?** Reduce the `800` to a smaller number.
* **Light flickering?** Ensure the resistor or wire is tight. RGB modules are sensitive to loose grounds.
