## 1. The Call to Adventure

Why settle for one color? With an RGB LED, you are a digital painter.
By mixing three primary colors (Red, Green, Blue) at different brightnesses, you can create millions of colors.
Your mission is to master the mixing process and build a smart mood lamp.

## 2. The Toolkit

* **1x Arduino Uno**
* **4x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

**Critical:** Use **PWM Pins** (marked with `~`). We need them to dim the lights to mix colors.

* **R (Red)** -> **Pin 3**
* **G (Green)** -> **Pin 5**
* **B (Blue)** -> **Pin 6**
* **- (Common)** -> **GND**

![RGB Mount](../../assets/1.0/RGB/RGB_Intro/mount_RGB.webp)

## 4. The Logic

We use `analogWrite` instead of `digitalWrite`.

* `digitalWrite`: 0 (OFF) or 1 (ON).
* `analogWrite`: 0 (OFF) to 255 (Full Brightness).

### The Code

```cpp
// Mission 1.24: The Prism of Power
const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;

void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}

void loop() {
  // Cycle primary colors
  setColor(255, 0, 0);   delay(1000); // Red
  setColor(0, 255, 0);   delay(1000); // Green
  setColor(0, 0, 255);   delay(1000); // Blue
  setColor(255, 0, 255); delay(1000); // Purple
}

void setColor(int r, int g, int b) {
  analogWrite(redPin, r);
  analogWrite(greenPin, g);
  analogWrite(bluePin, b);
}
```

## 6. Troubleshooting

* **Colors swapped?** Check the wiring. If Blue turns on when you call Red, swap Pins 3 and 6.
* **No color?** Ensure the Common Pin (usually marked `-`) is connected to **GND**.
* **Not mixing?** Ensure you are using PWM pins (3, 5, 6). Regular pins can't do "half-power".
