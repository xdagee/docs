# Introduction to the RGB LED

## 1. The Concept: Mixing Colors

**What is this?**
An **RGB LED** is special. It is not just one light, it is **three lights** in one package!

* **R** = Red
* **G** = Green
* **B** = Blue

By turning them on at different brightness levels, we can mix them to create **ANY** color (like Purple, Yellow, or White).

To do this, we need to use special pins on the Arduino called **PWM Pins** (Pins with the `~` symbol).

## 3. Standard Wiring (Important!)

> **Note:** The images in this guide might show different pins. **Please follow the table below** to ensure you can mix colors properly!

We will use Pins **3, 5, and 6** because they support "Color Mixing" (PWM).

| RGB Pin | Connection | Arduino Pin |
| :---: | :---: | :---: |
| **- (Minus)** | Ground | **GND** |
| **R** | Red Signal | **Pin 3** |
| **G** | Green Signal | **Pin 5** |
| **B** | Blue Signal | **Pin 6** |

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Define our color pins
const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;

void setup() {
  // 2. Set them all to OUTPUT
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}

void loop() {
  // 3. Red Only
  setColor(255, 0, 0); // Red ON, Green OFF, Blue OFF
  delay(1000);
  
  // 4. Green Only
  setColor(0, 255, 0);
  delay(1000);
  
  // 5. Blue Only
  setColor(0, 0, 255);
  delay(1000);
  
  // 6. Mix: Yellow (Red + Green)
  setColor(255, 255, 0);
  delay(1000);
  
  // 7. Mix: Purple (Red + Blue)
  setColor(255, 0, 255);
  delay(1000);
}

// Helper function to make setting colors easy
void setColor(int red, int green, int blue) {
  analogWrite(redPin, red);
  analogWrite(greenPin, green);
  analogWrite(bluePin, blue);
}
```

### Explaining `analogWrite`

* `digitalWrite` only does ON (5V) or OFF (0V).
* `analogWrite` allows us to choose a value between **0** (Off) and **255** (Full Brightness).
* By mixing `red=255`, `green=0`, `blue=255`, we get Purple!

## 5. Upload & Test

1. **Verify** and **Upload**.
2. Watch the LED. It should cycle through Red, Green, Blue, Yellow, Purple.

## 6. Troubleshooting

* **Colors look wrong?** (e.g., Red looks like Blue)
  * You swapped the wires. Check which wire goes to Pin 3, 5, and 6.
* **White light only?**
  * You might have connected the `-` pin to 5V instead of GND. Check the wiring.
