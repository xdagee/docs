## 1. The Call to Adventure

Why settle for one color? With an RGB LED, you are a painter.
By mixing three primary colors (Red, Green, Blue) at different brightnesses, you can create over **16 million** colors.
Your mission is to build a mood light.

## 2. The Toolkit

* **4x Jumper Wires**
* **1x Arduino Uno**

## 3. The Blueprint

**Critical:** Use **PWM Pins** (marked with `~`). We need them to dim the lights.

* **R (Red)** -> **Pin 3**
* **G (Green)** -> **Pin 5**
* **B (Blue)** -> **Pin 6**
* **- (Common)** -> **GND**

![RGB Mount](../../assets/1.0/RGB/RGB_Intro/mount_RGB.webp)

## 4. The Logic

We use `analogWrite` instead of `digitalWrite`.

* **digitalWrite**: 0 (OFF) or 1 (ON).
* **analogWrite**: 0 (OFF) to 255 (Full Brightness).

**Example: Making Yellow**
Red (255) + Green (255) + Blue (0) = **Yellow**.

### The Code

```cpp
// Mission 1.5: Color Theory
const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;

void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}

void loop() {
  // Red
  setColor(255, 0, 0);
  delay(1000);
  
  // Green
  setColor(0, 255, 0);
  delay(1000);
  
  // Blue
  setColor(0, 0, 255);
  delay(1000);
  
  // Purple (Red + Blue)
  setColor(255, 0, 255);
  delay(1000);
}

// Function to make code cleaner
void setColor(int r, int g, int b) {
  analogWrite(redPin, r);
  analogWrite(greenPin, g);
  analogWrite(bluePin, b);
}
```

## 6. Troubleshooting

* **Colors look wrong?**
  * Swap the wires. You might have Red connected to the Blue pin.
* **White light only?**
  * Did you plug the Common pin (Longest leg usually, or marked `-`) into 5V? It must go to **GND**.
* **Not fading/mixing?**
  * Ensure you are using Pins 3, 5, 6 (PWM). If you use Pin 4 or 7, it will just turn ON/OFF.
