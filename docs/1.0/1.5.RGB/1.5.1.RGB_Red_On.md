## 1. The Call to Adventure

Before we mix colors, we must master each channel. Red is the color of urgency and power.
Your mission is to calibrate the Red pin of the RGB module to act as a standalone security light.

## 2. The Toolkit

* **1x RGB LED Module**
* **1x Arduino Uno**
* **2x Jumper Wires** (GND + Red)

## 3. The Blueprint

* **R (Red)** -> **Pin 5** (Building for simple ON/OFF first)
* **- (Common)** -> **GND**

![Red Wiring](../../assets/1.0/RGB/RED_G_B/circuit_2.webp)

## 4. The Logic

**Algorithm:**

1. Identify the Red pin.
2. Set it to `OUTPUT`.
3. Power it `HIGH`.

### The Code

```cpp
// Mission 1.25: The Ruby Signal
const int red = 5;

void setup() {
  pinMode(red, OUTPUT);
}

void loop() {
  digitalWrite(red, HIGH); // Security Light ON
}
```

## 5. Upload & Test

1. Upload the code.
2. Observe: Is the light purely Red? No Green or Blue should be visible.
3. **Experiment**: Change `HIGH` to `LOW`. Does it vanish?

## 6. Troubleshooting

* **Wrong Color?** If it glows Green, the wires are swapped. Check which pin is labeled "R".
* **Very Dim?** Ensure the wire is pushed deep into the breadboard.
