## 1. The Call to Adventure

Imagine a defense shield with four layers of protection. In an emergency, we need to activate all four simultaneously.
Your mission is to program the master override that triggers the full shield array.

## 2. The Toolkit

* **1x Push Button**
* **4x LEDs**
* **1x Arduino Uno**
* **9x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

* **Override Switch**: Pin 13
* **Shield Layers**: Pins 12, 9, 4, 2
* **GND**: Unified Ground.

![Wiring Diagram](../../assets/1.0/Push_Button/Push_Button_4_LED/LED4.7.webp)

## 4. The Logic

**Algorithm:**

1. **Check Switch**: Is Pin 13 `LOW`?
2. **Activate**: If yes, turn all pins `HIGH`.
3. **Pulse**: Add a `delay(500)` to create a flashing "Warning" effect.

### The Code

```cpp
// Mission 1.16: The Shield Override
const int btn = 13;
const int layers[] = {12, 9, 4, 2};

void setup() {
  for(int i=0; i<4; i++) {
    pinMode(layers[i], OUTPUT);
  }
  pinMode(btn, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(btn) == LOW) {
    // Shield ACTIVE (Blinking)
    for(int i=0; i<4; i++) digitalWrite(layers[i], HIGH);
    delay(500);
    for(int i=0; i<4; i++) digitalWrite(layers[i], LOW);
    delay(500);
  } else {
    // Shield STANDBY (All OFF)
    for(int i=0; i<4; i++) digitalWrite(layers[i], LOW);
  }
}
```

## 5. Upload & Test

1. Upload the code.
2. Hold the button. Do the shields begin to pulse?
3. **Upgrade**: Can you change the code so they only blink once per press?

## 6. Troubleshooting

* **Not blinking?** Check your `delay()` calls inside the `if` statement.
* **Layer 4 (Pin 2) is dark?** Check the jump wire from Pin 2. It’s the furthest one on the board!
