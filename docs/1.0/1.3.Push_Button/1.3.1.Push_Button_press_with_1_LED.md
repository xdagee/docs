# Project 1.3: The Light Switch (Push Button)

## 1. The Concept: Digital Input

**What are we learning?**
So far, we have only *told* the Arduino what to do (Output).
Now, we will *listen* to the Arduino using a **Push Button** (Input).

We will use a special mode called `INPUT_PULLUP`.

* **Button Pressed** = Signal goes to **LOW** (0V).
* **Button Released** = Signal stays **HIGH** (5V).

> **Think of it like a doorbell.** When you press it, the circuit connects to the Ground, sending a "LOW" signal that tells the Arduino "I'm pressed!"

## 3. Wiring the Circuit

We need two circuits here: one for the LED (Output) and one for the Button (Input).

### A. The LED (Output)

1. **Positive (Long Leg)** -> **Pin 6**
2. **Negative (Short Leg)** -> **GND**

### B. The Button (Input)

Buttons have 4 legs, but we only need to use **2 legs diagonally across** from each other (or two on the same side if you are careful).

1. Connect **Leg A** to **Pin 2**.
2. Connect **Leg B** to **GND**.

> **Note:** We don't need a resistor for the button because we are using the Arduino's internal "Pullup" resistor!

![Push Button Circuit](../../assets/1.0/Push_Button/Push_Button_One_LED/Push_Button_Fig.7.webp)
*(Note: Your wiring might look slightly different depending on which holes you choose, but the connections to Pin 2, Pin 6, and GND must be correct!)*

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Define our names
const int buttonPin = 2;  // Button is on Pin 2
const int ledPin = 6;     // LED is on Pin 6

void setup() {
  // 2. Set up the LED as visual output
  pinMode(ledPin, OUTPUT);
  
  // 3. Set up the Button as Input with internal Pullup resistor
  // This is IMPORTANT: It keeps the signal HIGH when not pressed.
  pinMode(buttonPin, INPUT_PULLUP);
}

void loop() {
  // 4. Read the button state
  // Remember: LOW means pressed!
  int isPressed = digitalRead(buttonPin);

  if (isPressed == LOW) {
    // Button is pushed! Turn ON LED.
    digitalWrite(ledPin, HIGH); 
  } else {
    // Button is not pushed. Turn OFF LED.
    digitalWrite(ledPin, LOW);
  }
}
```

### Explaining the Logic

* `pinMode(buttonPin, INPUT_PULLUP);` -> This is the secret sauce. It sets the pin to be HIGH (5V) by default.
* `if (isPressed == LOW)` -> When we connect the button to GND (press it), the voltage drops to LOW. So `LOW` actually means "Action happening"!

## 6. Troubleshooting

* **LED is ON when I'm NOT pressing the button?**
  * You might have confused the logic. Check if you wrote `if (isPressed == HIGH)`.
  * Or, you might be using `INPUT` instead of `INPUT_PULLUP`.
* **Nothing happens?**
  * Check the LED wiring (Long leg to Pin 6).
  * Check the Button wiring (One leg to Pin 2, other to GND).
  * Try pressing the button firmly.
