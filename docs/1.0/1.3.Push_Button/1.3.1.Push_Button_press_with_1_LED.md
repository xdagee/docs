## 1. The Call to Adventure

Computers are smart, but sometimes they need human input. The **Push Button** is the simplest way to talk to a machine.
Your mission is to build a doorbell circuit: Input (Button) -> Processing -> Output (Light).

## 2. The Toolkit

* **1x Push Button** (The Input)
* **1x LED** (The Output)
* **1x Arduino Uno**

## 3. The Blueprint

We need two circuits here: one for the LED (Output) and one for the Button (Input).

### A. The LED (Output)

1. **Positive (Long Leg)** -> **Pin 6**
2. **Negative (Short Leg)** -> **GND**

### B. The Button (Input)

Buttons have 4 legs. Use **2 diagonal legs**.

1. **Leg A** -> **Pin 2**
2. **Leg B** -> **GND**

> **Note:** No resistor needed for the button! We use the internal one.

![Push Button Circuit](../../assets/1.0/Push_Button/Push_Button_One_LED/Push_Button_Fig.7.webp)

## 4. The Logic

We are using `INPUT_PULLUP` mode. This is "Inverse Logic".

* **Default (Not Pressed)** = 5V (HIGH)
* **Pressed (Connected to GND)** = 0V (LOW)

**Step-by-Step:**

1. **Read**: Check Pin 2. Is it HIGH or LOW?
2. **Decide**:
    * **IF** LOW (Pressed) -> Turn LED **ON**.
    * **ELSE** (Not Pressed) -> Turn LED **OFF**.

### The Code

```cpp
// Mission 1.3: The Light Switch
const int buttonPin = 2;  // Input
const int ledPin = 6;     // Output

void setup() {
  pinMode(ledPin, OUTPUT);
  // INPUT_PULLUP enables the internal 20k resistor
  pinMode(buttonPin, INPUT_PULLUP);
}

void loop() {
  // Read the button (Remember: Low = Pressed)
  int isPressed = digitalRead(buttonPin);

  if (isPressed == LOW) {
    digitalWrite(ledPin, HIGH); // Pressed! Light ON
  } else {
    digitalWrite(ledPin, LOW);  // Released. Light OFF
  }
}
```

## 5. Upload & Test

1. Upload the code.
2. Press the button. Does the light turn on?
3. Release. Does it turn off?

## 6. Troubleshooting

* **LED is ON when I'm NOT pressing?**
  * You might have `if (isPressed == HIGH)`. Remember, `INPUT_PULLUP` means LOW is the active action!
* **Button loose?**
  * Push buttons must snap firmly into the middle trench of the breadboard.
