## 1. The Call to Adventure

In complex systems, one switch might need to activate multiple lights (e.g., turning on both headlights of a car).
Your mission is to scale up your circuit to control two independent zones with one finger.

## 2. The Toolkit

* **1x Push Button**
* **2x LEDs** (Red & Green)
* **1x Arduino Uno**
* **5x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

* **Button**: Pin 13
* **LED 1**: Pin 9
* **LED 2**: Pin 7
* **GND**: Connect all Ground legs to the same GND pin.

## 4. The Logic

**Algorithm:**

1. **Monitor**: Watch Pin 13.
2. **Action**: If Pin 13 goes `LOW` (Pressed), set Pins 9 and 7 to `HIGH`.

### The Code

```cpp
// Mission 1.14: The Twin Safety
const int btn = 13;
const int ledA = 9;
const int ledB = 7;

void setup() {
  pinMode(ledA, OUTPUT);
  pinMode(ledB, OUTPUT);
  pinMode(btn, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(btn) == LOW) {
    digitalWrite(ledA, HIGH);
    digitalWrite(ledB, HIGH);
  } else {
    digitalWrite(ledA, LOW);
    digitalWrite(ledB, LOW);
  }
}
```

## 5. Upload & Test

1. Upload the code.
2. Hold the button. Do both "Zones" light up?
3. **Challenge**: Can you make the LEDs alternate (one ON, one OFF) when the button is pressed?

## 6. Troubleshooting

* **One light is off?** Check the wiring for that specific LED. Is the long leg connected to the correct pin?
* **Wires getting messy?** Use the Blue "GND" strip on your breadboard to connect all negative wires together.
