## 1. The Call to Adventure

Emergency vehicles use alternating lights to grab attention.
Your mission is to create a "Police Style" signal by flipping between two LEDs.

## 4. The Logic

**Algorithm:**

1. **State A**: Red `HIGH`, White `LOW`. Wait.
2. **State B**: Red `LOW`, White `HIGH`. Wait.

### The Code

```cpp
// Mission 1.4: The Alternator
const int red = 6;
const int white = 5;

void setup() {
  pinMode(red, OUTPUT);
  pinMode(white, OUTPUT);
}

void loop() {
  // State A
  digitalWrite(red, HIGH);
  digitalWrite(white, LOW);
  delay(500);
  
  // State B
  digitalWrite(red, LOW);
  digitalWrite(white, HIGH);
  delay(500);
}
```

## 5. Upload & Test

1. Upload the code.
2. Does the light "jump" between the two LEDs?
3. **Speed Up**: Change `delay(500)` to `delay(100)` for a faster strobe effect.

## 6. Troubleshooting

* **Both blink at the same time?** Check your code—did you forget to set the other one to `LOW` in each step?
* **One light is much brighter?** LEDs have different power needs. This is normal, but double check your wiring if one is barely glowing.
