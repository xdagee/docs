# Project 1.1: Light Up an LED

## 1. The Concept: Digital Output

**What are we learning?**
We are going to turn on a Light Emitting Diode (LED).
To do this, we need to send an electrical signal from the Arduino to the LED.

* **HIGH** signal = 5V (On)
* **LOW** signal = 0V (Off)

We will use a command called `digitalWrite()` to send this signal.

## 3. Wiring the Circuit

**Caution:** LEDs have polarity! They have a **positive (+)** leg and a **negative (-)** leg.

* **Long Leg (+):** Connects to the Signal (Pin 6).
* **Short Leg (-):** Connects to Ground (GND).

**Step 1:** Insert the LED into the breadboard.
![LED fixed on breadboard](../../assets/1.0/LED/LED_ON/led_on_breadboard.webp)

**Step 2:** Connect the **Positive (Long Leg)** to Arduino **Pin 6**.
*(Using a Red wire helps you remember it's positive!)*
![Red wire connected](../../assets/1.0/LED/LED_ON/red_wire_connected.webp)

**Step 3:** Connect the **Negative (Short Leg)** to Arduino **GND**.
*(Using a Black or Blue wire helps you remember it's Ground!)*
![Blue wire connected](../../assets/1.0/LED/LED_ON/blue_wire_connected.webp)

**Step 4:** Plug the Arduino into your computer using the Blue USB cable.

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Give the pin a name so it's easier to remember
int ledPin = 6;

void setup() {
  // 2. Tell Arduino that this pin is for OUTPUT (sending power out)
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // 3. Turn the LED ON (HIGH voltage)
  digitalWrite(ledPin, HIGH);
}
```

### Explaining the lines

* `int ledPin = 6;` -> We create a variable named `ledPin` and set it to 6. Now, whenever we say `ledPin`, the computer knows we mean Pin 6.
* `pinMode(ledPin, OUTPUT);` -> Pins can be inputs (listening) or outputs (talking). We want to talk to the LED, so we set it to **OUTPUT**.
* `digitalWrite(ledPin, HIGH);` -> Send 5V to the pin. **Let there be light!**

3. Look at your board. Is the LED on?

## 6. Troubleshooting

* **LED not turning on?**
  * Try flipping the LED. Remember, the **Long leg** must go to Pin 6.
  * Check if the wires are pushed all the way in.
  * Check if you uploaded the code successfully (Look for "Done uploading").
* **Dim light?**
  * Ensure you are using a digital pin (0-13), not an analog pin.
