## 1. The Call to Adventure

Sometimes, one light isn't enough. You need the full power of the grid.
Your mission is to wire and control five independent lights to create a "Superlight" array.

## 2. The Toolkit

* **5x LEDs** (Red, White, Yellow, Green, Blue)
* **1x Arduino Uno**
* **10x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

* **Pins**: 6, 5, 4, 3, 2
* **GND**: Common Ground

![Wiring Diagram](../../assets/1.0/LED/FIVE_LEDs_Blink/observation.webp)

## 4. The Logic

**Algorithm:**

1. **Define**: 5 Signal Pins.
2. **Setup**: All as `OUTPUT`.
3. **Loop**: Turn all `HIGH`.

### The Code

```cpp
// Mission 1.9: The Superlight
const int pins[] = {6, 5, 4, 3, 2};

void setup() {
  for(int i=0; i<5; i++) {
    pinMode(pins[i], OUTPUT);
  }
}

void loop() {
  for(int i=0; i<5; i++) {
    digitalWrite(pins[i], HIGH);
  }
}
```

## 5. Upload & Test

## 6. Troubleshooting

* **Blue light not working?** Pin 2 is at the end of the row. Ensure the wire is firmly in both the Arduino and the Breadboard.
* **Voltage Drop?** If all lights are slightly dim, it's because the Arduino is sharing power between five LEDs. This is normal for a USB-powered board.
