## 1. The Call to Adventure

Imagine a dark runway at night. Pilots need a sequence of lights to guide their path.
Your mission is to program a sequential pulse that travels down the line from Pin 6 to Pin 3.

## 2. The Toolkit

* **4x LEDs** (Red, White, Yellow, Green)
* **1x Arduino Uno**
* **8x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

## 4. The Logic

**Algorithm:**

1. Turn Pin 6 ON/OFF.
2. Turn Pin 5 ON/OFF.
3. Turn Pin 4 ON/OFF.
4. Turn Pin 3 ON/OFF.

### The Code

```cpp
// Mission 1.8: Runway Pulse
const int p1 = 6;
const int p2 = 5;
const int p3 = 4;
const int p4 = 3;

void setup() {
  pinMode(p1, OUTPUT);
  pinMode(p2, OUTPUT);
  pinMode(p3, OUTPUT);
  pinMode(p4, OUTPUT);
}

void loop() {
  pulsate(p1);
  pulsate(p2);
  pulsate(p3);
  pulsate(p4);
}

void pulsate(int pin) {
  digitalWrite(pin, HIGH);
  delay(100); // Fast pulse
  digitalWrite(pin, LOW);
  delay(100);
}
```

## 5. Upload & Test

1. Upload the code.
2. Watch the "Light" travel down your breadboard.
3. **Upgrade**: Can you make the sequence go backwards (3 to 6) after it finishes?

## 6. Troubleshooting

* **Lights stay ON?** Ensure you are using `digitalWrite(pin, LOW)` at the end of each pulse.
* **Sequence out of order?** Check that your pins match the order on the breadboard.
