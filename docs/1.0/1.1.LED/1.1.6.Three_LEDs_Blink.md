## 1. The Call to Adventure

Communication is vital during a rescue. If you can't speak, you use light.
Your mission is to program a three-stage light sequence that signals for help at different levels of urgency.

## 2. The Toolkit

* **3x LEDs** (Red, White, Yellow)
* **1x Arduino Uno**
* **6x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

* **Red**: Pin 6
* **White**: Pin 5
* **Yellow**: Pin 4
* **GND**: Common Ground

## 4. The Logic

**Algorithm:**

1. **Stage 1**: Turn Pin 6 ON/OFF.
2. **Stage 2**: Turn Pin 5 ON/OFF.
3. **Stage 3**: Turn Pin 4 ON/OFF.

### The Code

```cpp
// Mission 1.6: The SOS Beacon
const int led1 = 6;
const int led2 = 5;
const int led3 = 4;

void setup() {
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
  pinMode(led3, OUTPUT);
}

void loop() {
  // Signal 1
  digitalWrite(led1, HIGH); delay(1000);
  digitalWrite(led1, LOW);  delay(1000);
  
  // Signal 2
  digitalWrite(led2, HIGH); delay(1000);
  digitalWrite(led2, LOW);  delay(1000);
  
  // Signal 3
  digitalWrite(led3, HIGH); delay(1000);
  digitalWrite(led3, LOW);  delay(1000);
}
```

## 5. Upload & Test

1. Upload the code.
2. Watch the beacon cycle through the zones.
3. **Upgrade**: Can you make the Red light blink twice as fast as the Yellow light?

## 6. Troubleshooting

* **Sequence skipping?** Check your `delay()` calls. If you forget one, the light will turn OFF and then ON so fast you won't even see it blink!
* **Colors swapped?** Check that Pin 6 is truly connected to the Red LED.
