## 1. The Call to Adventure

You've built signals and runway guides. Now, it's time for **fluid motion**.
Your mission is to create a "Scanner" effect where the light bounces back and forth like a famous crime-fighting car.

## 2. The Toolkit

* **5x LEDs** (Red, White, Yellow, Green, Blue)
* **1x Arduino Uno**
* **10x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

* **Signal Pins**: 6, 5, 4, 3, 2
* **GND**: Common Ground

![Wiring Diagram](../../assets/1.0/LED/FIVE_LEDs_Blink/observation.webp)

## 4. The Logic

**Algorithm:**

1. **Forward**: Pulse Pin 6 -> 5 -> 4 -> 3 -> 2.
2. **Reverse**: Pulse Pin 3 -> 4 -> 5 -> 6.

### The Code

```cpp
// Mission 1.10: The Knight Rider
int pins[] = {6, 5, 4, 3, 2};

void setup() {
  for(int i=0; i<5; i++) {
    pinMode(pins[i], OUTPUT);
  }
}

void loop() {
  // 1. Move Forward
  for(int i=0; i<5; i++) {
    digitalWrite(pins[i], HIGH);
    delay(100);
    digitalWrite(pins[i], LOW);
  }
  
  // 2. Move Backward
  for(int i=3; i>0; i--) { // Start at green (3rd index)
    digitalWrite(pins[i], HIGH);
    delay(100);
    digitalWrite(pins[i], LOW);
  }
}
```

## 5. Upload & Test

1. Upload the code.
2. Does the light "bounce" off the ends of the breadboard?
3. **Upgrade**: Change the delay to `50` for a high-speed scan.

## 6. Troubleshooting

* **Stuck at one end?** Check your logic—did you forget to turn the LED `LOW` before moving to the next one?
* **Wired backwards?** If the scan starts at the Blue LED instead of the Red, simply swap your pin numbers in the `pins[]` array.
