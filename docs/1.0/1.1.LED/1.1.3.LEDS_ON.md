## 1. The Call to Adventure

One light is a signal. Two lights are a **system**.
Your mission is to double the power and control two independent lights simultaneously.

## 2. The Toolkit

* **2x LEDs** (Red & White)
* **1x Arduino Uno**
* **4x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

* **LED 1 (Red)**: Pin 6 (+) to Pin 6, (-) to GND.
* **LED 2 (White)**: Pin 5 (+) to Pin 5, (-) to GND.

![Wiring Diagram](../../assets/1.0/LED/DOUBLE_LED_ON/observation.webp)

## 4. The Logic

**Algorithm:**

1. **Define**: Use Pin 6 and Pin 5.
2. **Setup**: Set both pins to `OUTPUT`.
3. **Loop**: Turn both `HIGH`.

### The Code

```cpp
// Mission 1.3: Twin Stars
const int led1 = 6;
const int led2 = 5;

void setup() {
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
}

void loop() {
  digitalWrite(led1, HIGH);
  digitalWrite(led2, HIGH);
}
```

## 5. Upload & Test

1. Upload the code.
2. Do both project lights glow?
3. **Challenge**: Can you make just one turn off while the other stays on?

## 6. Troubleshooting

* **Only one light is on?** Check the wires for the one that is off. Does it have both a Power wire and a Ground wire?
* **Colors looking weird?** Ensure you didn't mix up the Positive and Negative legs of the second LED.
