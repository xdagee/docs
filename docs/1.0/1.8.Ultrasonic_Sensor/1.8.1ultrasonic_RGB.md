## 1. The Call to Adventure

Cars use ultrasonic sensors to help drivers park safely.
Your mission is to build this system. It must combine **Input** (Distance) and **Output** (Color) to make a smart decision.

## 4. The Logic

We are combining the skills from Mission 1.5 (RGB) and Mission 2.1 (Ultrasonic).

**Step-by-Step:**

1. **Measure**: Get distance in cm.
2. **Decide**:
    * **IF** Distance < 10cm -> **RED** (Danger!).
    * **ELSE** -> **BLUE** (Safe).
3. **Act**: Send color command.

### The Code

```cpp
// Mission 1.8: Reverse Parking Sensor
const int trigPin = 9;
const int echoPin = 10;

const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;

long duration;
int distance;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // 1. Measure Distance
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  duration = pulseIn(echoPin, HIGH);
  distance = duration * 0.034 / 2;

  // 2. Logic
  Serial.print("Distance: ");
  Serial.println(distance);

  if (distance < 10) {
    // DANGER! Red
    setColor(255, 0, 0); 
  } else {
    // SAFE. Blue
    setColor(0, 0, 255);
  }
  delay(100);
}

void setColor(int r, int g, int b) {
  analogWrite(redPin, r);
  analogWrite(greenPin, g);
  analogWrite(bluePin, b);
}
```

## 6. Troubleshooting

* **Distance always 0?**
  * Check Trig/Echo wires (9 and 10).
  * Check VCC (Must be 5V).
* **Colors wrong?**
  * Check RGB wiring (Pins 3, 5, 6).

## 7. Extensions & Upgrades

**Challenge**: The Warning Zone

* **Upgrade**: Add a "Yellow" zone between 10cm and 20cm.
* **Code**: Use `else if (distance < 20) { setColor(255, 255, 0); }`.
  * **Close (< 10cm):** LED should be **Red**.
  * **Medium (10-20cm):** LED should be **Blue**.
  * **Far (> 20cm):** LED should be **Green**.

### Not working?

* **LED Dark?** Check if you connected the RGB GND pin to Arduino GND.
* **Distance is always 0?** Check the Trig/Echo wires. Make sure they are not swapped.
* **Colors wrong?** You might have swapped the R, G, B pins. Check your wiring vs the code.
