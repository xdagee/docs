# Project 1.8.1: Ultrasonic Sensor with RGB Module

## 1. The Concept: Distance & Color

**What are we learning?**
In this project, we will combine an **input** (Ultrasonic Sensor) and an **output** (RGB Module). We will learn how to make decisions using `if/else` statements.

* **If** an object is close, the light turns **RED** (Danger!).
* **If** an object is far away, the light turns **GREEN** (Safe).

This is the same logic used in car reversing sensors!

## 3. Wiring the Circuit

We need to connect two modules. Use the breadboard to make it easier.

### Ultrasonic Sensor Connections

* **VCC** -> Arduino **5V**
* **GND** -> Arduino **GND**
* **Trig** -> Arduino Pin **9**
* **Echo** -> Arduino Pin **10**

### RGB Module Connections

* **R (Red)** -> Arduino Pin **3**
* **G (Green)** -> Arduino Pin **5**
* **B (Blue)** -> Arduino Pin **6**
* **- (GND)** -> Arduino **GND**

> **Checkpoint:** Check your connections carefully! The Ultrasonic sensor needs 5V to work.

## 4. The Code

Copy the code below into your Arduino IDE.

```cpp
// Define Pins
const int trigPin = 9;
const int echoPin = 10;
const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;

// Variables for distance
long duration;
int distance;

void setup() {
  // Set up the Ultrasonic Sensor pins
  pinMode(trigPin, OUTPUT); // Sends the sound wave
  pinMode(echoPin, INPUT);  // Listens for the echo

  // Set up the RGB LED pins
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);

  // Start Serial Monitor (so we can see the distance on screen)
  Serial.begin(9600);
}

void loop() {
  // 1. Clear the trigPin
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);

  // 2. Send a 10 microsecond pulse to trigger the sensor
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // 3. Measure the duration of the echo
  duration = pulseIn(echoPin, HIGH);

  // 4. Calculate distance in cm
  distance = duration * 0.034 / 2;

  // Print distance to Serial Monitor
  Serial.print("Distance: ");
  Serial.println(distance);

  // 5. Logic: Change color based on distance
  if (distance < 10) {
    // Too close! Turn RED
    setColor(255, 0, 0); 
  } else if (distance < 20) {
    // Getting closer... Turn BLUE/YELLOW
    setColor(0, 0, 255);
  } else {
    // Safe distance. Turn GREEN
    setColor(0, 255, 0);
  }
}

// Helper function to set color easily
void setColor(int red, int green, int blue) {
  analogWrite(redPin, red);
  analogWrite(greenPin, green);
  analogWrite(bluePin, blue);
}
```

## 5. Testing & Troubleshooting

1. **Upload** the code to your Arduino.
2. **Open Serial Monitor** (Magnifying glass icon top right). Set baud rate to **9600**.
3. Move your hand in front of the ultrasonic sensor.
    * **Close (< 10cm):** LED should be **Red**.
    * **Medium (10-20cm):** LED should be **Blue**.
    * **Far (> 20cm):** LED should be **Green**.

### Not working?

* **LED Dark?** Check if you connected the RGB GND pin to Arduino GND.
* **Distance is always 0?** Check the Trig/Echo wires. Make sure they are not swapped.
* **Colors wrong?** You might have swapped the R, G, B pins. Check your wiring vs the code.
