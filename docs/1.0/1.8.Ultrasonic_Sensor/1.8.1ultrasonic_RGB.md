## 1. The Call to Adventure

Bats navigate in total darkness by bouncing sound off walls. We call this **Echolocation**.
Your mission is to build a high-tech distance sensor for a car that uses this same principle to prevent collisions.

## 2. The Toolkit

## 4. The Logic

**Algorithm:**

1. **Trig**: Send a sound pulse.
2. **Echo**: Measure how long it takes to come back.
3. **Math**: Convert time into **Centimeters**.
4. **Reaction**: If < 10cm, turn the light **RED**. Otherwise, keep it **BLUE**.

### The Code

```cpp
// Mission 1.35: The Bat's Ear
const int trigPin = 9;
const int echoPin = 10;
const int red = 3;
const int blue = 6;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(red, OUTPUT);
  pinMode(blue, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // 1. Send the Pulse
  digitalWrite(trigPin, LOW);  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  // 2. Measure Echo
  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;

  // 3. React
  if (distance < 10) {
    digitalWrite(red, HIGH);
    digitalWrite(blue, LOW);
  } else {
    digitalWrite(red, LOW);
    digitalWrite(blue, HIGH);
  }
}
```

## 5. Upload & Test

1. Upload the code.
2. Move your hand toward the sensor. Does the light change color?
3. **Challenge**: Can you make it blink Red very fast when you get even closer (< 5cm)?

## 6. Troubleshooting

* **Reading is 0?** Check the Trig and Echo wires. If they are swapped, the code will wait forever for a signal.
* **Logic inverted?** Ensure you are using `distance < 10` for the Red light.
