## 1. The Call to Adventure

Streetlights shouldn't be on during the day—it wastes energy. We need a sensor that can "see" sunlight.
Your mission is to use a **Light Dependent Resistor (LDR)** to measure brightness and report it to the city control center (your computer).

## 2. The Toolkit

* **1x LDR Module** (The Eye)
* **3x Jumper Wires**
* **1x Arduino Uno**

## 3. The Blueprint

The LDR module has 3 or 4 pins. We will use the **Analog Output (AO)** to get a precise number.

* **VCC** -> **5V**
* **GND** -> **GND**
* **AO (Analog)** -> **Pin A0**

![LDR Wiring](../../assets/1.0/LDR_Module/ldr_wire_4.webp)

## 4. The Logic

Digital pins are just 0 or 1. Analog pins can see **1024** levels of brightness!

* **0** = Pitch Black.
* **1023** = Blinding Light.

**Step-by-Step:**

1. **Define**: LDR is on `A0`.
2. **Setup**: Start the Serial Monitor (Communication line).
3. **Loop**:
    * **Read**: Get the brightness number (`analogRead`).
    * **Report**: Send it to the computer (`Serial.println`).

### The Code

```cpp
// Mission 1.6: Light Intensity Checker
const int ldrPin = A0;

void setup() {
  // Start communication with the computer
  Serial.begin(9600);
}

void loop() {
  // 1. Read the brightness (0-1023)
  int brightness = analogRead(ldrPin);
  
  // 2. Report it
  Serial.print("Brightness Level: ");
  Serial.println(brightness);
  
  // 3. Slow down so we can read it
  delay(100);
}
```

## 5. Upload & Test

1. Upload the code.
2. **Open Serial Monitor** (Top Right Magnifying Glass).
3. Cover the sensor with your hand. Does the number go down?
4. Shine a flashlight on it. Does the number go up?

## 6. Troubleshooting

* **Numbers are random?**
  * Check if you used **AO** (Analog) or **DO** (Digital). `analogRead` needs `AO`.
* **Value always 1023 or 0?**
  * Check VCC (5V) and GND connections.
  * Adjust the little blue screw (Potentiometer) on the module if it has one—it acts as a sensitivity tuner.
