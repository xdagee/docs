## 1. The Call to Adventure

Streetlights shouldn't be on during the day—it wastes energy. We need a sensor that can "see" sunlight just like a human eye.
Your mission is to use a **Light Dependent Resistor (LDR)** to measure brightness and report the environment's state to your computer.

## 2. The Toolkit

* **1x LDR Module** (The Eye)
* **1x Arduino Uno**
* **3x Jumper Wires**
* **1x Breadboard**

## 3. The Blueprint

The LDR module uses the **Analog Output (AO)** to give a precise number between 0 and 1023.

* **VCC** -> **5V**
* **GND** -> **GND**
* **AO (Analog)** -> **Pin A0**

![LDR Wiring](../../assets/1.0/LDR_Module/ldr_wire_4.webp)

## 4. The Logic

Digital pins are just 0 or 1. Analog pins can see **1024** unique levels of brightness!

* **0** = Pitch Black.
* **1023** = Blinding Light.

### The Code

```cpp
// Mission 1.32: The Night Watch
const int ldrPin = A0;

void setup() {
  // Start communication with the computer
  Serial.begin(9600);
}

void loop() {
  // 1. Read the brightness (0-1023)
  int brightness = analogRead(ldrPin);
  
  // 2. Report it to the Serial Monitor
  Serial.print("Current Light Level: ");
  Serial.println(brightness);
  
  delay(100); // Slow down for readability
}
```

## 5. Upload & Test

1. Upload the code.
2. **Open Serial Monitor** (Top Right Magnifying Glass icon).
3. Cover the sensor with your hand. Does the number drop?
4. **Upgrade**: Connect an LED to Pin 13 and make it turn on ONLY when it's dark!

## 6. Troubleshooting

* **Numbers are random?** Check if you used **AO** (Analog) or **DO** (Digital). `analogRead` needs the Analog pin.
* **Value always 1023?** Check your GND connection. If the circuit is "Open", it might float to the maximum value.
