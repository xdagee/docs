# Project 1.2: Buzzing with Sound

## 1. The Concept: Making Noise

**What are we learning?**
We are going to use a **Buzzer** to make a sound.
Just like the LED, the Buzzer is a connection output.

* **HIGH** signal = Sound ON (Beep!)
* **LOW** signal = Sound OFF (Silence)

## 3. Wiring the Circuit

**Caution:** The Buzzer has polarity!

* **Long Leg (+):** Connects to the Signal (Pin 3).
* **Short Leg (-):** Connects to Ground (GND).

**Step 1:** Insert the Buzzer into the breadboard.
![LED fixed on breadboard](../../assets/1.0/BUZZER/buzzer_inserting.webp)

**Step 2:** Connect the **Positive (Long Leg)** to Arduino **Pin 3**.

**Step 3:** Connect the **Negative (Short Leg)** to Arduino **GND**.
![LED fixed on breadboard](../../assets/1.0/BUZZER/buzzer_wire_2.webp)

**Step 4:** Plug in the Arduino.

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Define the pin for the buzzer
int buzzerPin = 3;

void setup() {
  // 2. Set the buzzer pin as an OUTPUT
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  // 3. Turn the buzzer ON
  digitalWrite(buzzerPin, HIGH);
  
  // Wait for 1 second (1000 milliseconds)
  delay(1000); 
  
  // 4. Turn the buzzer OFF
  digitalWrite(buzzerPin, LOW);
  
  // Wait for 1 second 
  delay(1000);
}
```

### Explaining the lines

* `delay(1000);` -> This pauses the program for 1000 milliseconds (which is 1 second). This creates a "Beep... Silence... Beep" pattern.

## 6. Troubleshooting

* **No Sound?**
  * Check the polarity (Long leg to Pin 3).
  * Check your wires.
  * Ensure code uploaded successfully.
* **Continuous sound (no beeping)?**
  * Did you include the `delay()`? If you don't pause, it might just stay on (or off) so fast you can't tell!

## Conclusion

Now you have sound! You can combine this with an LED to make a specialized alarm. Try changing the `delay` numbers to make it beep faster!
