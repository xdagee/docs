## 4. The Logic

**Algorithm:**

1. **Define**: Use Pin 3 for the signal.
2. **Setup**: Set Pin 3 to `OUTPUT`.
3. **Loop**:
    * Turn `HIGH` (ON) to beep.
    * Wait 1 second.
    * Turn `LOW` (OFF) to silence.
    * Wait 1 second.

### The Code

```cpp
// Mission 1.11: The Silent Alarm
const int buzzerPin = 3;

void setup() {
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  digitalWrite(buzzerPin, HIGH); // Sound ON
  delay(1000);
  digitalWrite(buzzerPin, LOW);  // Sound OFF
  delay(1000);
}
```

## 5. Upload & Test

1. Upload the code.
2. Listen! Do you hear the steady alarm?
3. **Experiment**: Change the delay to `100` for a high-speed panic alarm.

## 6. Troubleshooting

* **No sound?**
  * Did you remove the **REMOVE SEAL** sticker from the top of the buzzer?
  * Check if the buzzer legs are deep enough in the breadboard.
* **Sounds like clicking?** If it doesn't beep, your kit might have a "Passive Buzzer". Try using `tone(3, 1000);` instead of `digitalWrite`.
