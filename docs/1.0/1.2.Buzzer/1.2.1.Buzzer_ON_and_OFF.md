## 3. The Blueprint

**Caution:** The Buzzer has polarity!

* **Long Leg (+):** Connects to **Pin 3** (Signal).
* **Short Leg (-):** Connects to **GND** (Ground).

![Wiring Diagram](../../assets/1.0/BUZZER/buzzer_wire_2.webp)

## 4. The Logic

We control sound just like we control light—by turning the power ON and OFF.

1. **Define**: Give Pin 3 the name `buzzerPin`.
2. **Setup**: Configure Pin 3 as an **OUTPUT**.
3. **Loop**:
    * **ON**: `digitalWrite(HIGH)` -> Beep!
    * **Wait**: `delay(1000)` -> Hold the beep.
    * **OFF**: `digitalWrite(LOW)` -> Silence.
    * **Wait**: `delay(1000)` -> Hold the silence.

### The Code

```cpp
// Mission 1.2: Buzzing with Sound
int buzzerPin = 3;

void setup() {
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  digitalWrite(buzzerPin, HIGH); // Beep
  delay(1000);                   // Wait 1 sec
  
  digitalWrite(buzzerPin, LOW);  // Silence
  delay(1000);                   // Wait 1 sec
}
```

## 6. Troubleshooting

* **No Sound?**
  * Did you remove the **Sticker** on top of the buzzer? (REMOVE SEAL).
  * Check polarity: Long leg must go to Pin 3.
* **Clicking only?**
  * You might have a "Passive Buzzer" that needs a frequency (tone), but most kits come with Active Buzzers. If it just clicks, try using `tone(3, 1000);`.
