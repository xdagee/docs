## 1. The Call to Adventure

Imagine switching off your room light from your bed just by clapping.
Your mission is to enable "Hands-Free" control.

## 2. The Toolkit

* **1x Sound Sensor** (Input)
* **1x LED** (Output)
* **1x Arduino Uno**

## 3. The Blueprint

* **Sound Pin**: 2 (Digital Output from module)
* **LED**: 6
* **VCC/GND**: 5V/GND

![connect white wire](../../assets/3.0/Smart_Clap_Device/7.webp)

## 4. The Logic

**Algorithm:**

1. **Read Sensor**: Digital input.
2. **Toggle Logic**: `state =! state` (If 1, make 0. If 0, make 1).
3. **Debounce**: Wait for the sound to stop before reading again.

### The Code

```cpp
// Mission 3.6: Voice Control
const int soundPin = 2; // Digital Pin (Adjust sensitivity on module)
const int ledPin = 6;

int state = LOW;

void setup() {
  pinMode(soundPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int noise = digitalRead(soundPin);
  
  if (noise == HIGH) {
    // Detected Sound
    state = !state; // Toggle (Flip)
    digitalWrite(ledPin, state);
    delay(500); // Wait for silence (Debounce)
  }
}
```

## 5. Upload & Test

1. Upload code.
2. Clap loudly. Light should toggle.
3. **Sensitivity**: You MUST adjust the blue potentiometer on the sensor module until the LED on the module flickers ONLY when you clap.

## 6. Troubleshooting

* **Light just flickers randomlly?**
  * Sensor is too sensitive. Turn the screw.
* **Won't turn off?**
  * Increase delay to `1000` to prevent "Double switching".
