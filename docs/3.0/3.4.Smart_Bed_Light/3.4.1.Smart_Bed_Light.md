## 1. The Call to Adventure

Why fumble for switches in the dark? A smart home should know when you need light.
Your mission is to use the **LDR (Light Dependent Resistor)** to control your room light automatically.

## 2. The Toolkit

* **1x LDR Sensor** (Input)
* **1x LED** (Output)
* **1x Resistor** (10k Ohm or 220 Ohm depending on circuit)
* **1x Arduino Uno**

## 3. The Blueprint

* **LDR Analog**: Pin A0
* **LED Positive**: Pin 6
* **LED Negative**: GND
* **VCC/GND**: 5V/GND

![LDR fixed on beardboard](../../assets/3.0/Smart_Street_Light_System/circuit_7.webp)

## 4. The Logic

**Algorithm:**

1. **Read Light Level**.
2. **Logic**: If Darkness Detected (< Threshold), Turn LED ON.
    * *Note*: The original legacy code had this backwards (`> 500`). Usually, low reading = dark.
3. **Bonus**: Use `analogWrite` to fade it in!

### The Code

```cpp
// Mission 3.4: Smart Bed Light
const int ldrPin = A0;
const int ledPin = 6;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int brightness = analogRead(ldrPin);
  Serial.print("Brightness: ");
  Serial.println(brightness);

  // If it's DARK (Low number)
  if (brightness < 300) { 
    digitalWrite(ledPin, HIGH); // Turn Light ON
  } else {
    digitalWrite(ledPin, LOW);  // Turn Light OFF
  }
  
  delay(200);
}
```

## 5. Upload & Test

1. Upload code.
2. Cover the sensor. The light should turn ON.
3. Uncover. The light should turn OFF.

## 6. Troubleshooting

* **Opposite behavior?**
  * Change `< 300` to `> 300`. Some LDR modules are wired differently (pull-up vs pull-down).
* **Flickering?**
  * Add a small "buffer" (hysteresis) or just tweak the threshold.
