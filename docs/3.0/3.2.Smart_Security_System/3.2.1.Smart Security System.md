## 1. The Call to Adventure

The city bank needs a new security system.
Your mission is to build a "Proximity Alarm" that detects invisible intruders using sound waves.

## 2. The Toolkit

## 3. The Blueprint

* **Ultrasonic Trig**: Pin 6
* **Ultrasonic Echo**: Pin 7
* **Buzzer +**: Pin 8
* **LED +**: Pin 9
* **GND**: Common Ground

## 4. The Logic

**Algorithm:**

1. **Ping**: Send a sound wave.
2. **Listen**: Measure how long it takes to return.
3. **Calculate**: Distance = Time x Speed of Sound.
4. **Decide**: If Distance < 20cm -> **ALARM!**

### The Code

```cpp
// Mission 3.2: Smart Security System
const int trigPin = 6;
const int echoPin = 7;
const int buzzerPin = 8;
const int ledPin = 9;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  long duration, distance;

  // 1. Send Pulse
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // 2. Measure Pulse
  duration = pulseIn(echoPin, HIGH);

  // 3. Calculate Distance (cm)
  distance = (duration / 2) / 29.1;

  Serial.print(distance);
  Serial.println(" cm");

  // 4. Security Logic
  if (distance > 0 && distance < 20) {
    // INTRUDER ALERT!
    digitalWrite(ledPin, HIGH);
    tone(buzzerPin, 1000); // 1 kHz sound
  } else {
    // Safe
    digitalWrite(ledPin, LOW);
    noTone(buzzerPin);
  }
  
  delay(100);
}
```

## 5. Upload & Test

1. Upload code.
2. Place your hand far away (Safe).
3. Move hand closer (< 20cm).
4. **BEEP!** LED ON.

## 6. Troubleshooting

* **Alarm triggering constantly?**
  * Ultrasonic sensors can be noisy. Ensure it's pointing at empty space.
* **Distance is 0?**
  * Check VCC (5V) and GND connections on the sensor. 0 usually means "Unplugged".
