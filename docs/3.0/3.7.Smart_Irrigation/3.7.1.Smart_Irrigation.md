## 1. The Call to Adventure

The **Smart City** grows its own food in vertical farms. These farms use sensors to monitor soil moisture so they water only when needed — no waste, no dead crops.

But the city's water reservoir is running low. Every drop counts. The Farm Manager needs an automated system that measures soil moisture, makes a decision, and controls a water valve without human help.

Your mission: **Build the irrigation brain.** Read the soil. Decide if it is dry. Open the valve only when necessary.

## 4. The Logic

The system has three states, like a dashboard for your farm:

| Condition | Sensor Value | Action |
|---|---|---|
| **Wet** | 0–400 | Valve closed. Blue LED ON. |
| **Moist** | 400–700 | Valve closed. Green LED ON. |
| **Dry** | 700–1023 | Valve opens 90. Red LED ON. |

The LDR value goes **up** when it gets darker. Dark soil means dry. Bright soil means wet.

**Step by step:**

1. Read the sensor: `analogRead(A0)` gives a number from 0 to 1023.
2. Compare the number against your thresholds.
3. Pick the right action for each state.
4. Print the status to the Serial Monitor so you can watch it live.

This is called **multi-threshold decision logic**. Instead of one `if/else` (do this OR that), you use `if/else if/else` (do this, OR that, OR the other).

## 5. The Code

```cpp
// Mission 3.7: Smart Farm — Automated Irrigation Controller

#include <Servo.h>

// Sensor
const int moisturePin = A0;

// LEDs
const int redLed = 6;
const int greenLed = 7;
const int blueLed = 8;

Servo valveServo;
int valvePosition = 0;    // 0 = closed, 90 = open

// Thresholds
const int dryThreshold = 700;   // Above this = dry
const int wetThreshold = 400;   // Below this = wet

void setup() {
  pinMode(redLed, OUTPUT);
  pinMode(greenLed, OUTPUT);
  pinMode(blueLed, OUTPUT);

  valveServo.attach(9);
  valveServo.write(0);          // Start closed

  Serial.begin(9600);
  Serial.println("=== Smart Farm Irrigation Controller ===");
}

void loop() {
  int moisture = analogRead(moisturePin);

  // Show raw value on the dashboard
  Serial.print("Moisture: ");
  Serial.print(moisture);

  // --- DECISION LOGIC: Three states ---
  if (moisture < wetThreshold) {
    // WET: Soil is wet enough. Keep valve closed.
    valvePosition = 0;
    valveServo.write(valvePosition);
    digitalWrite(blueLed, HIGH);
    digitalWrite(greenLed, LOW);
    digitalWrite(redLed, LOW);
    Serial.println(" | Status: WET — Valve closed");
  }
  else if (moisture < dryThreshold) {
    // MOIST: Soil is fine. Keep valve closed.
    valvePosition = 0;
    valveServo.write(valvePosition);
    digitalWrite(blueLed, LOW);
    digitalWrite(greenLed, HIGH);
    digitalWrite(redLed, LOW);
    Serial.println(" | Status: MOIST — Valve closed");
  }
  else {
    // DRY: Open the valve and water the crops.
    valvePosition = 90;
    valveServo.write(valvePosition);
    digitalWrite(blueLed, LOW);
    digitalWrite(greenLed, LOW);
    digitalWrite(redLed, HIGH);
    Serial.println(" | Status: DRY — Watering!");
  }

  delay(1000);  // Check soil every second
}
```

### Key lines explained

- `analogRead(moisturePin)` — Reads the sensor. Returns 0 (bright = wet) to 1023 (dark = dry).
- `if (moisture < wetThreshold)` — Checks if the value is below the wet boundary.
- `else if (moisture < dryThreshold)` — Only runs if the first condition was false. Checks for the middle zone.
- `else` — Catches everything above `dryThreshold`. If it is not wet and not moist, it must be dry.
- `valveServo.write(90)` — Turns the servo to 90 degrees to open the valve.
- `Serial.println(...)` — Sends the status to your computer so you can see what the system is doing.

## 6. Troubleshooting

At Level 3, you diagnose problems like a real engineer. Use the **Serial Monitor** (Tools > Serial Monitor) to see what your system is reporting.

**Valve never moves**

1. What value does `Moisture:` show in the Serial Monitor? If it stays near 0, the LDR module is in bright light. Cover it with your hand. Does the value rise above 700?
2. If the value changes but the servo does not move, check the signal wire. Is it connected to Pin 9?
3. If the servo twitches but does not hold position, it may not be getting enough power. See the note in the Blueprint section.

**LEDs behave wrong**

1. Check your pin numbers. Does `const int redLed = 6` match the wire plugged into Pin 6?
2. Check your LED polarity. The long leg goes to the resistor.
3. Check your thresholds. If the LDR reads 500 but both thresholds are set to 400 and 700, you are in the "moist" zone — the green LED should be on.

**Board resets when servo moves**

- The servo draws a large current spike on startup. Keep its wires short. If the problem persists, power the servo from an external 5V supply.

**All LEDs stay off**

- Did you add `pinMode(...)` for each LED in `setup()`? This is a common Level 1 mistake.
- Did you connect the GND rail on the breadboard back to the Arduino's GND?

## 7. Extensions

Your farm controller works. Now make it smarter.

**Challenge 1: Variable watering**

Instead of opening the valve fully (90), make the angle proportional to how dry the soil is. Use `map(moisture, 700, 1023, 0, 180)` to convert the dry range into a valve position. Drier soil = wider open.

**Challenge 2: Night detection**

Add a second LDR to monitor sunlight. If it is dark (night), do not water even if the soil is dry. Plants rest at night and absorb water less efficiently.

**Challenge 3: Data logging**

Modify the code to print the moisture reading and valve position as comma-separated values that could be saved to a file:

```
Moisture,Valve,Status
450,0,MOIST
810,90,DRY
320,0,WET
```

**Challenge 4: Manual override**

Add a push button. When pressed, the valve opens for 5 seconds regardless of moisture level. The Farm Manager needs manual control for emergencies.
