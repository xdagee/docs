# Project 2.8.1: Color Control with Push Button

## 1. The Concept

We will create a **Color Cycle** light.
Every time you press the button, the RGB LED changes color:
**Red -> Green -> Blue -> OFF -> (Repeat)**

## 2. Components Needed

* Arduino Uno
* Push Button
* RGB LED Module
* Jumper Wires

## 3. Wiring the Circuit

> **Standard Wiring**: We adhere to the standard pins to ensure reliability.

| Component | Pin Label | Arduino Pin |
| :--- | :--- | :--- |
| **RGB LED** | **R** (Red) | **Pin 3** |
| | **G** (Green) | **Pin 5** |
| | **B** (Blue) | **Pin 6** |
| | **-** (GND) | **GND** |
| **Button** | **Leg A** | **Pin 2** |
| | **Leg B** | **GND** |

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Define Pins
const int buttonPin = 2;
const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;

// Variables to store state
int buttonState = 0;       // Current reading
int lastButtonState = 0;   // Previous reading
int colorMode = 0;         // 0=Red, 1=Green, 2=Blue, 3=OFF

void setup() {
  // 2. Configure Output Pins (RGB)
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
  
  // 3. Configure Input Pin (Button)
  // We use INPUT_PULLUP so we don't need a resistor!
  pinMode(buttonPin, INPUT_PULLUP);
}

void loop() {
  // 4. Read the button
  buttonState = digitalRead(buttonPin);

  // 5. Detect a "Click" (Transition from HIGH to LOW)
  if (buttonState == LOW && lastButtonState == HIGH) {
    colorMode++; // Go to next color
    if (colorMode > 3) {
      colorMode = 0; // Reset back to start
    }
    delay(200); // Debounce (wait a bit to prevent double clicks)
  }
  
  lastButtonState = buttonState; // Remember for next loop

  // 6. Set Color based on Mode
  if (colorMode == 0) {
    setColor(255, 0, 0); // RED
  } else if (colorMode == 1) {
    setColor(0, 255, 0); // GREEN
  } else if (colorMode == 2) {
    setColor(0, 0, 255); // BLUE
  } else {
    setColor(0, 0, 0);   // OFF
  }
}

// Helper Function
void setColor(int red, int green, int blue) {
  analogWrite(redPin, red);
  analogWrite(greenPin, green);
  analogWrite(bluePin, blue);
}
```

## 5. Troubleshooting

* **Button doesn't work?** Ensure one leg is on **Pin 2** and the non-connected leg is on **GND**. We use `INPUT_PULLUP` code to make this simple wiring work.
* **Colors don't change?** Try pressing the button firmly. The debounce delay helps prevent accidental double-clicks.
