## 1. The Call to Adventure

Static lights are boring. We want a light that changes to match our mood.
Your mission is to build a "State Machine" that cycles through colors.

## 4. The Logic

We use a variable `colorMode` to remember where we are.

* 0 = Red
* 1 = Green
* 2 = Blue
* 3 = OFF

### The Code

```cpp
// Mission 2.8: Mood Light
const int buttonPin = 2;
const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;

int colorMode = 0;       
int lastButtonState = HIGH; // Start HIGH (Not pressed)

void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);
}

void loop() {
  int buttonState = digitalRead(buttonPin);

  // Detect CLICK (High -> Low)
  if (buttonState == LOW && lastButtonState == HIGH) {
    colorMode++;
    if (colorMode > 3) colorMode = 0; // Reset loop
    delay(200); // Debounce
  }
  
  lastButtonState = buttonState;

  // Apply Color
  if (colorMode == 0) setColor(255, 0, 0);       // Red
  else if (colorMode == 1) setColor(0, 255, 0);  // Green
  else if (colorMode == 2) setColor(0, 0, 255);  // Blue
  else setColor(0, 0, 0);                        // OFF
}

void setColor(int r, int g, int b) {
  analogWrite(redPin, r);
  analogWrite(greenPin, g);
  analogWrite(bluePin, b);
}
```

## 5. Upload & Test

1. Upload code.
2. Click the button. Does it change?
3. Hold the button. It should NOT change rapidly (thanks to the logic).

## 6. Troubleshooting

* **Colors erratic?**
  * This is often a loose wire on the breadboard. Wiggle them gently.
* **Skipping colors?**
  * Increase `delay(200)` to `delay(300)` for better debouncing.
