## 1. The Call to Adventure

Your mission is to build a civilized alert system: The Doorbell.

## 2. The Toolkit

* **1x Arduino Uno**

## 3. The Blueprint

* **Buzzer +**: Pin 3
* **Buzzer -**: GND
* **Button A**: Pin 2
* **Button B**: GND

![Wiring Diagram](../../assets/2.0/2.2.Push%20Button%20+%20Buzzer/push4.webp)

## 4. The Logic

**Step-by-Step:**

1. Check Button.
2. **IF** Pressed (LOW):
    * Turn Buzzer ON.
    * Wait a tiny bit (Debounce).
3. **ELSE**:
    * Turn Buzzer OFF.

### The Code

```cpp
// Mission 2.6: Doorbell
const int buttonPin = 2;
const int buzzerPin = 3;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  int isPressed = digitalRead(buttonPin);
  
  if (isPressed == LOW) {
    // Ding!
    digitalWrite(buzzerPin, HIGH);
  } else {
    // Silence
    digitalWrite(buzzerPin, LOW);
  }
}
```

## 5. Upload & Test

1. Upload code.
2. Press the button.
3. Adjust the sticker on the buzzer if it's too quiet (or too loud!).

## 6. Troubleshooting

* **Buzzer clicking?**
  * Try `tone(3, 1000);` instead of `digitalWrite` if it's a passive buzzer.
* **Sound won't stop?**
  * Check your `if/else` logic. Did you forget the `else` block to turn it off?
