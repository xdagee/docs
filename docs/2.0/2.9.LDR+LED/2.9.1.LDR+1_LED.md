## 1. The Call to Adventure

Leaving lights on during the day wastes power. We need a system that "knows" when the sun sets.
Your mission is to use the **LDR (Light Dependent Resistor)** to control an LED.

## 2. The Toolkit

* **1x LDR Sensor** (Input)
* **1x LED** (Output)
* **1x Arduino Uno**

## 3. The Blueprint

* **LDR Analog**: Pin A0
* **LED Positive**: Pin 6
* **LED Negative**: GND
* **VCC**: 5V
* **GND**: GND

![Wiring Diagram](../../assets/2.0/3.1.LDR+LED/LDR_and_LED1/image-4.webp)

## 4. The Logic

**Step-by-Step:**

1. **Read** the Light level (0-1023).
2. **Compare**: Is it darker than our threshold? (e.g., < 300).
3. **Act**: Turn LED HIGH or LOW.

### The Code

```cpp
// Mission 2.9: Smart Streetlight
const int ldrPin = A0;
const int ledPin = 6;

void setup() {
  Serial.begin(9600);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int brightness = analogRead(ldrPin);
  Serial.println(brightness); // Calibrate using this number

  // Threshold: Adjust based on your room (cover sensor to test)
  if (brightness < 300) {
    digitalWrite(ledPin, HIGH); // Night time
  } else {
    digitalWrite(ledPin, LOW);  // Day time
  }
  delay(100);
}
```

## 5. Upload & Test

1. Upload code.
2. Open **Serial Monitor** to see the numbers.
3. Cover the sensor with your hand. Does the LED turn on?

## 6. Troubleshooting

* **LED flickers?**
  * You are right on the "Threshold". Adjust the number `300` up or down to stop the flickering.
* **Always ON?**
  * Your room might be very dark. Lower the threshold number.
