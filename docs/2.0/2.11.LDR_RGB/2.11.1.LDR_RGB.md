# Project 2.11.1: Automatic Street Light (LDR + RGB)

## 1. The Concept

We will create an **Automatic Street Light** that turns on when it gets dark.

* **Bright Light**: LED is **OFF**.
* **Darkness**: LED turns **ON** (White/Yellow).

We use a **Photoresistor (LDR)** to measure light intensity.

## 2. Components Needed

* Arduino Uno
* LDR Sensor Module
* RGB LED Module
* Jumper Wires

## 3. Wiring the Circuit

> **Standard Wiring**: RGB uses Pins 3, 5, 6 for color mixing.

| Component | Pin Label | Arduino Pin |
| :--- | :--- | :--- |
| **RGB LED** | **R** (Red) | **Pin 3** |
| | **G** (Green) | **Pin 5** |
| | **B** (Blue) | **Pin 6** |
| | **-** (GND) | **GND** |
| **LDR Sensor** | **VCC** | **5V** |
| | **GND** | **GND** |
| | **AO** (Analog) | **A0** |

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Define Pins
const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;
const int ldrPin = A0;

void setup() {
  Serial.begin(9600);
  
  // 2. Configure Output Pins
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}

void loop() {
  // 3. Read Light Level (0 to 1023)
  int lightLevel = analogRead(ldrPin);
  
  Serial.print("Light Level: ");
  Serial.println(lightLevel);

  // 4. Logic: Dark vs Bright
  // (Adjust '500' based on your room's light)
  if (lightLevel < 500) { 
    // DARK: Turn ON (White Light)
    setColor(255, 255, 255);
  } else {
    // BRIGHT: Turn OFF
    setColor(0, 0, 0);
  }
  
  delay(100);
}

// Helper Function
void setColor(int red, int green, int blue) {
  analogWrite(redPin, red);
  analogWrite(greenPin, green);
  analogWrite(bluePin, blue);
}
```

## 5. Troubleshooting

* **Light turns on when it's bright?** Your LDR might be wired inversely or you need to flip logic `<` to `>`.
* **Is it too sensitive?** Change the number `500`. Higher number = turns on sooner (in brighter light). Lower number = needs to be darker.
* **Colors are wrong?** Check RGB wiring (3, 5, 6).
