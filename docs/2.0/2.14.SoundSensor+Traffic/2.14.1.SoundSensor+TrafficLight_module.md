## 4. The Logic

**Algorithm:**

1. **Wait**: Light is Red by default.
2. **Listen**: If Sound > Threshold:
    * Cycle Green -> Yellow -> Red.
    * Wait a bit.

### The Code

```cpp
// Mission 2.14: Voice Commander
const int soundPin = A0;
const int red = 5;
const int yellow = 6;
const int green = 7;

void setup() {
  pinMode(red, OUTPUT);
  pinMode(yellow, OUTPUT);
  pinMode(green, OUTPUT);
  Serial.begin(9600);
  
  // Start Red
  digitalWrite(red, HIGH);
}

void loop() {
  int noise = analogRead(soundPin);
  
  if (noise > 500) {
    // COMMAND RECEIVED!
    cycleLights();
  }
}

void cycleLights() {
  // Go Green
  digitalWrite(red, LOW);
  digitalWrite(green, HIGH);
  delay(3000);
  
  // Go Yellow
  digitalWrite(green, LOW);
  digitalWrite(yellow, HIGH);
  delay(1000);
  
  // Go Red
  digitalWrite(yellow, LOW);
  digitalWrite(red, HIGH);
  
  // Debounce (Don't trigger again immediately)
  delay(2000); 
}
```
