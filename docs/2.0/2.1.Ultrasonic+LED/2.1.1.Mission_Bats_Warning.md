# Mission 2.1: The Bat's Warning

> **Role**: Neighborhood Engineer  
> **Objective**: Build a proximity alarm that warns us when danger is too close.

---

## 1. The Call to Adventure

In the **Neighborhood**, blind corners are dangerous. Cars and pedestrians crash because they can't "see" what's coming.

We need a system that acts like a Bat: sending out sound waves to detect obstacles in the dark. If something gets too close, the Alarm (LED) must trigger.

## 2. The Toolkit

* **1x Ultrasonic Sensor (HC-SR04)**: The "Bat Eyes".
* **1x LED**: The Warning Light.
* **4x Jumper Wires**: For the Sensor.

## 3. The Blueprint

The Ultrasonic Sensor has 4 pins. Be careful!

* **VCC** -> **5V**
* **GND** -> **GND**
* **Trig** (Trigger) -> **Pin 11** (Sends the shout)
* **Echo** (Listener) -> **Pin 12** (Hears the echo)
* **LED Positive** -> **Pin 13**

## 4. The Logic

How do we measure distance with sound?
`Distance = (Time * Speed of Sound) / 2`

1. **Trigger**: Send a 10-microsecond pulse (Shout).
2. **Echo**: Wait for the pulse to bounce back (Listen).
3. **Calculate**: Use the time to find centimeters.

### The Code

```cpp
// Mission 2.1: The Bat's Warning
const int trigPin = 11;
const int echoPin = 12;
const int ledPin = 13;

long duration;
int distance;

void setup() {
  pinMode(trigPin, OUTPUT); // Mouth (Speaks)
  pinMode(echoPin, INPUT);  // Ear (Listens)
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);       // Open Communications to PC
}

void loop() {
  // 1. Clear the throat
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);

  // 2. SHOUT! (Send sound wave)
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // 3. LISTEN (Measure how long it takes to return)
  duration = pulseIn(echoPin, HIGH);

  // 4. Calculate Distance (Speed of sound is 0.034 cm/us)
  distance = duration * 0.034 / 2;

  // 5. Logic: Is it too close? (< 20cm)
  if (distance < 20) {
    digitalWrite(ledPin, HIGH); // DANGER! Turn ON.
  } else {
    digitalWrite(ledPin, LOW);  // Safe. Turn OFF.
  }
  
  // Debugging: Print to screen
  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");
}
```
