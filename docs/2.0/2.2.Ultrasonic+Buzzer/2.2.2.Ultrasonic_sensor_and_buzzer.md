## 1. The Call to Adventure

A secure Neighborhood needs protection. We can't watch every door ourselves.
Your mission is to build an automated sentry using the **Ultrasonic Sensor** (Input) and **Buzzer** (Output).

## 2. The Toolkit

* **1x Ultrasonic Sensor** (The Sentry)
* **1x Buzzer** (The Alarm)
* **1x Arduino Uno**

## 3. The Blueprint

* **Ultrasonic Trig** -> **Pin 3**
* **Ultrasonic Echo** -> **Pin 2**
* **Buzzer Positive** -> **Pin 4**
* **Buzzer Negative** -> **GND**
* **VCC** -> **5V**
* **GND** -> **GND**

> **Note**: We are using different pins than Mission 2.1. Pay attention!

## 4. The Logic

**Step-by-Step:**

1. **Pulse**: Send a sound wave from the Trig pin.
2. **Listen**: Count how long it takes to return to Echo.
3. **Calculate**: `Distance = Time x Speed`.
4. **Decide**:
    * **IF** Distance < 30cm (Intruder!) -> **Buzzer ON**.
    * **ELSE** (Clear) -> **Buzzer OFF**.

### The Code

```cpp
// Mission 2.2: Intruder Alarm
const int trigPin = 3;
const int echoPin = 2;
const int buzzerPin = 4;

long duration;
int distance;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // 1. Send Ping
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // 2. Read Echo
  duration = pulseIn(echoPin, HIGH);
  distance = duration * 0.034 / 2;
  
  // 3. Serial Monitor
  Serial.print("Range: ");
  Serial.println(distance);

  // 4. Security Logic
  if (distance < 30) {
    // INTRUDER DETECTED!
    digitalWrite(buzzerPin, HIGH);
    tone(buzzerPin, 1000); // 1KHz sound
    delay(200);
    noTone(buzzerPin);     // Pulse the sound
    delay(200); 
  } else {
    // SAFE
    digitalWrite(buzzerPin, LOW);
    noTone(buzzerPin);
  }
}
```

## 5. Upload & Test

1. Upload the code.
2. Place the sensor facing a door or hallway.
3. Walk past it. Does it scream?

## 6. Troubleshooting

* **Continuous Beeping?**
  * Check if something is permanently in front of the sensor.
  * Check connections for VCC and GND.
* **Clicking Noise?**
  * Try `tone(buzzerPin, 1000)` instead of `digitalWrite` if using a passive buzzer.
