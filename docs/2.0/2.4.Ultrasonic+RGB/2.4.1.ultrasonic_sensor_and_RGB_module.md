# Project 2.4.1: Smart Distance Warning (Ultrasonic + RGB)

## 1. The Concept

We will build a "Smart Parking Assistant".

* **Far away (> 20cm)**: Light is **GREEN** (Safe).
* **Getting close (< 20cm)**: Light turns **RED** (Warning!).

To do this, we combine the **Ultrasonic Sensor** (Input) and **RGB LED** (Output).

## 2. Components Needed

* Arduino Uno
* Ultrasonic Sensor (HC-SR04)
* RGB LED Module
* Jumper Wires

## 3. Wiring the Circuit

> **Important:** We are using **Standard Wiring** for the RGB to allow color mixing. This might differ from the images, but it is necessary for the code to work correctly!

| Component | Pin Label | Arduino Pin |
| :--- | :--- | :--- |
| **RGB LED** | **R** (Red) | **Pin 3** |
| | **G** (Green) | **Pin 5** |
| | **B** (Blue) | **Pin 6** |
| | **-** (GND) | **GND** |
| **Ultrasonic** | **VCC** | **5V** |
| | **GND** | **GND** |
| | **Trig** | **Pin 12** |
| | **Echo** | **Pin 11** |

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Define Pins
const int redPin = 3;
const int greenPin = 5;
const int bluePin = 6;

const int trigPin = 12;
const int echoPin = 11;

void setup() {
  Serial.begin(9600); // Start serial communication
  
  // 2. Configure RGB Output
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
  
  // 3. Configure Ultrasonic Sensor
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  // 4. Measure Distance
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;
  
  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  // 5. Logic: Close vs Far
  if (distance < 20) {
    // Too Close! Show RED
    setColor(255, 0, 0); 
  } else {
    // Safe! Show GREEN
    setColor(0, 255, 0); 
  }
  
  delay(100);
}

// Helper Function
void setColor(int red, int green, int blue) {
  analogWrite(redPin, red);
  analogWrite(greenPin, green);
  analogWrite(bluePin, blue);
}
```

## 5. Troubleshooting

* **Always reads 0cm?** Check VCC/GND on the sensor. Ensure Trig=12 and Echo=11.
* **Colors are wrong?** Check your RGB wiring (R=3, G=5, B=6).
