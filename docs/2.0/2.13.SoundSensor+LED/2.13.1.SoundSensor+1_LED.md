## 1. The Call to Adventure

Imagine walking into your room and just clapping to turn on the lights.
Your mission is to build a "Toggle Switch" triggered by sound.

## 2. The Toolkit

## 3. The Blueprint

* **Sound Analog**: A0
* **LED Positive**: Pin 8

* **VCC**: 5V
* **GND**: GND

## 4. The Logic

**Algorithm:**

1. **Listen**: Read measurement.
2. **Trigger**: If loud (> threshold), toggle the `state` variable.
3. **Act**: If `state` is 1, Light HIGH. If `state` is 0, Light LOW.

### The Code

```cpp
// Mission 2.13: Clap Switch
const int soundPin = A0;
const int ledPin = 8;
int lightState = 0; // 0=Off, 1=On

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int noise = analogRead(soundPin);
  Serial.println(noise); // Use this to calibrate

  // Threshold check (Adjust 600 based on serial monitor)
  if (noise > 600) {
    // CLAP DETECTED!
    if (lightState == 0) {
      lightState = 1;
    } else {
      lightState = 0;
    }
    
    // Wait for the clap to finish (Debounce)
    delay(500); 
  }

  // Update light based on state
  if (lightState == 1) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}
```

## 5. Upload & Test

1. Upload code.
2. Clap near the sensor. Does the light toggle?
3. If it flickers, increase the `delay(500)` or adjust the threshold.

## 6. Troubleshooting
