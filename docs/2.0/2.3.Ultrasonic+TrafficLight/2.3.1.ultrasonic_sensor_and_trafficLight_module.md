# Project 2.3.1: Intelligent Traffic Control

## 1. The Concept

We will simulate a "Smart Traffic Light" that changes based on traffic density (distance).

* **Car Far Away**: Green Light (Flow).
* **Car Approaching**: Yellow Light (Caution).
* **Car Stopped (Close)**: Red Light (Stop).

## 2. Components Needed

* Arduino Uno
* Ultrasonic Sensor (HC-SR04)
* Traffic Light Module
* Jumper Wires

## 3. Wiring the Circuit

> **Standard Wiring**: We adhere to the standard pins from Level 1.

| Component | Pin Label | Arduino Pin |
| :--- | :--- | :--- |
| **Traffic Light** | **R** (Red) | **Pin 5** |
| | **Y** (Yellow) | **Pin 6** |
| | **G** (Green) | **Pin 7** |
| | **GND** | **GND** |
| **Ultrasonic** | **VCC** | **5V** |
| | **GND** | **GND** |
| | **Trig** | **Pin 12** |
| | **Echo** | **Pin 11** |

## 4. The Code

Copy this code into your Arduino IDE.

```cpp
// 1. Define Pins
const int redPin = 5;
const int yellowPin = 6;
const int greenPin = 7;

const int trigPin = 12;
const int echoPin = 11;

void setup() {
  Serial.begin(9600);
  
  // 2. Configure Traffic Light
  pinMode(redPin, OUTPUT);
  pinMode(yellowPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  
  // 3. Configure Ultrasonic
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  // 4. Measure Distance
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;
  
  Serial.print("Distance: ");
  Serial.println(distance);

  // 5. Intelligent Logic
  // First, turn everything off
  digitalWrite(redPin, LOW);
  digitalWrite(yellowPin, LOW);
  digitalWrite(greenPin, LOW);

  if (distance < 10) {
    // STOP! (Car is very close)
    digitalWrite(redPin, HIGH);
  } else if (distance < 30) {
    // CAUTION (Car is approaching)
    digitalWrite(yellowPin, HIGH);
  } else {
    // GO (Road is clear)
    digitalWrite(greenPin, HIGH);
  }
  
  delay(100);
}
```

## 5. Troubleshooting

* **Lights don't match the car position?** Check your specific connection. Remember **Red is Pin 5** and **Green is Pin 7**.
* **Sensor reading 0?** Check the VCC and GND connections on the Ultrasonic sensor.
