## 1. The Call to Adventure

Every machine needs a switch. From nuclear power plants to your toaster, the **Push Button** is the king of control.
Your mission is to wire a button that gives you total control over the light.

## 2. The Toolkit

* **1x Push Button** (Input)
* **1x LED** (Output)
* **1x Arduino Uno**

## 3. The Blueprint

* **LED Long Leg (+)** -> **Pin 13**
* **LED Short Leg (-)** -> **GND**
* **Button Leg A** -> **Pin 2**
* **Button Leg B** -> **GND**

> **Pro Tip**: Pin 13 has a built-in resistor, so for this specific pin, you *can* skip the external resistor if you are quick. But adding one is always safer!

![Wiring Diagram](../../assets/2.0/2.1.Push%20Button%20+%20LED/wire_4.webp)

## 4. The Logic

We use **INPUT_PULLUP**.

* **Pressed** = LOW (0V).
* **Released** = HIGH (5V).

### The Code

```cpp
// Mission 2.5: The Controller
const int buttonPin = 2;
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP); // Activates internal resistor
}

void loop() {
  int state = digitalRead(buttonPin);
  
  if (state == LOW) {
    // Button Pressed
    digitalWrite(ledPin, HIGH);
  } else {
    // Button Released
    digitalWrite(ledPin, LOW);
  }
}
```

## 5. Upload & Test

## 6. Troubleshooting

* **Light works backwards?** (OFF when pressed?)
  * Change `if (state == LOW)` to `if (state == HIGH)`. But remember, `LOW` is technically "Pressed" in this wiring.
* **Nothing happens?**
  * Ensure the Button is connected to **GND**, not 5V.
